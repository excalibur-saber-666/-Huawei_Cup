## 这类题的本质

这是“复杂生产规则下的离散事件仿真 + 多目标组合优化”。真正困难的不是给遗传算法调参数，而是把车辆、车道、横移机、返回道、优先规则和加工时间转换为一个不会产生非法状态的解码器。稳妥路线是：

    决策编码 → 状态转移/事件仿真 → 硬约束检查 → 分目标评分 → 搜索改进 → 回放验证

## 通用解题框架

1. 画系统图：资源、队列、车辆属性、入口/出口、并发关系和优先级。
2. 建立离散事件仿真器，定义状态、事件、转移条件和耗时；用小样例逐帧回放。
3. 区分硬约束与软目标。硬约束进入解码/修复，软目标保留原始量后再归一化评分。
4. 给出至少一个可解释 baseline：FIFO、固定车道、贪心最早完成时间或规则调度。
5. 再选择优化器：规模小用 MILP/CP-SAT/动态规划，规模大用局部搜索、模拟退火、GA、ALNS。
6. 让领域知识进入初始解、邻域和修复算子，不只在结果讨论中口头解释。
7. 将最优染色体重新交给仿真器，从头回放并导出每车每时刻位置、资源占用和全部约束检查。

## 模型与工具选择

| 条件 | 推荐方法 | 关键验证 |
|---|---|---|
| 状态/资源交互复杂 | 离散事件仿真、状态机、时空网络 | 事件顺序、死锁、资源冲突、逐步回放 |
| 中小规模且线性约束 | MILP、CP-SAT | 最优 gap、求解时间、不可行解释 |
| 有明显阶段和小状态空间 | 动态规划、标签算法 | 状态充分性、支配规则、规模增长 |
| 大规模排列/车道选择 | GA、SA、禁忌、ALNS | 可行率、多种子分布、相对 baseline 提升 |
| 多目标权衡 | 目标规划、ε-constraint、NSGA-II | 原始目标、权重敏感性、Pareto 前沿 |
| 在线扰动/滚动到达 | 滚动时域、仿真优化、MPC式重调度 | 延迟、插单、设备故障与恢复 |

## 写作和图表模板

- 摘要：系统任务 → 共用仿真内核 → 问题一优化 → 问题二约束变化 → 关键数值与验证。
- 正文：规则翻译表 → 状态/事件定义 → 目标与约束 → baseline → 搜索算法 → 回放与验证。
- 机制图：横向画物料流，纵向标资源/队列；动态规则不要只用大段文字。
- 算法图：搜索器、解码器、约束检查、评分器四个模块必须分开。
- 结果表：分目标原值、标准化分、总分、运行时间、可行性；不要只报总适应度。
- 甘特/状态图：颜色只编码车辆类型或状态之一，车号/车道/时间轴保持一致。
