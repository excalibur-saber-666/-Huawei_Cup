## 这类题的本质

这是“带工艺结构的二维切割 + 容量受限订单分组 + 分组和排样耦合”题。关键不只是提高几何利用率，而是让每个方案同时满足产品完整、方向、三阶段齐头切、订单不可拆、批次数量/面积和材质约束。推荐将问题分成可行结构生成、完整需求覆盖和上层组批三个接口清晰的模块。

## 通用解题框架

1. 写清原片、产品项、允许旋转、锯缝、齐头切阶段和完整性约束。
2. 计算面积下界与简单 First/Best-Fit baseline，建立结果标尺。
3. 将工艺结构表示为 item → stack → stripe → bin，设计始终生成可行解的构造器。
4. 小规模用 MILP/CP-SAT 或列生成求精确/下界，大规模用贪心、搜索树、价值修正或局部搜索。
5. 用未完成需求作为状态反复生成排样图，避免只优化单块原片而不能覆盖全部订单。
6. 组批先保证订单完整、数量、面积和材质约束，再比较聚类、图划分或受约束优化。
7. 将排样器的估算成本反馈给组批，至少用局部换单/并批/拆批改进顺序分解。
8. 输出后逐块回代重叠、边界、切割阶段、需求数量和批次约束。

## 模型和工具选择

| 规模和结构 | 方法 | 最低验证 |
|---|---|---|
| 小规模、需最优性 | MILP、CP-SAT、列生成/分支定价 | 最优 gap、面积下界、运行时间 |
| 大规模快速可行解 | FFDH/Bottom-Left、层级贪心、构造型启发式 | 可行率、利用率、与小规模精确解差距 |
| 贪心末期残件严重 | SVC、局部搜索、交换/重排、ALNS | 多初值、多随机种子、尾部原片利用率 |
| 订单相似且有容量 | 受约束层次聚类、图划分、容量聚类 | 所有容量约束、批次数、排样后真实成本 |
| 组批—排样耦合强 | 双层/联合 MILP、分解协调、排样成本代理 + 邻域搜索 | 顺序分解 baseline、运行时间—质量权衡 |

推荐工具：OR-Tools CP-SAT、Gurobi/Pyomo、NumPy/pandas；二维排样图用 Matplotlib 绘制，同时编写几何可行性检查器。

## 写作和图表模板

- 摘要：分别报告排样和组批的目标、核心算法、原片数/利用率及运行时间。
- 正文：工艺结构图 → 决策变量/约束 → 单块排样生成器 → 完整方案算法 → 组批算法 → 可行性与性能对照。
- 伪代码：必须列输入、输出、终止条件、需求更新和最优方案更新。
- 结果表：数据集、面积下界、原片数、gap、利用率、批次数、运行时间；不要只报告平均单板利用率。
- 排样图：统一原片比例和颜色映射，标明 item ID/尺寸/方向，另给低利用率尾板案例用于诊断。
