## 这类题的本质

这是“干预影响评估 + 需求与供给匹配 + 设施选址 + 多级应急物流”。稳妥主线是：

    疫情/人口/供需/地理数据
    → 反事实与需求估计
    → 城区配额与设施选址
    → 上游—中游—下游网络
    → 容量车辆路径与应急情景
    → 可执行预案

其中“评价、分配、选址、路径”是四类不同任务，不能用一个综合评分模型包办。

## 通用解题框架

1. 统一时间与空间粒度：城区/街道/小区、日/周、需求/接收/发放/库存不能混用。
2. 反事实评估先画政策时间线，选择 SIR/SEIR、ITS、合成控制或分区面板模型；用干预前回测检验外推能力。
3. 需求估计以人口、疫情、库存和消耗为输入，输出数量与不确定区间；评价分数只用于优先级，不直接当物资量。
4. 设施选址先列候选点、容量、覆盖半径、道路时间、固定成本与备用性，再选 p-median、最大覆盖、CFLP 或聚类初筛。
5. 建上游—中游—下游网络，明确每条边的物资、车辆、时间和容量；分层求解后必须做全局供需守恒检查。
6. 路径层使用 CVRP/HVRP/VRPTW；小规模精确解，大规模 ALNS、GA/SA 或 OR-Tools，并设计可行性修复。
7. 做需求上浮、道路中断、设施失效、车辆减少的应急情景，输出备用节点与重规划规则。

## 模型和工具选择

| 任务 | 推荐方法 | 工具与验证 |
|---|---|---|
| 疫情干预反事实 | SIR/SEIR + 回测；中断时间序列；合成控制/面板 | SciPy/statsmodels；拟合窗口、安慰剂时点、参数区间 |
| 需求/短缺评价 | 描述统计、库存平衡、熵权/TOPSIS 仅作优先级 | 单位与供需守恒、权重敏感性 |
| 连续空间初筛 | K-means/GMM/DBSCAN | 轮廓系数、稳定性、中心到候选场地映射 |
| 离散设施选址 | p-median、最大覆盖、CFLP、鲁棒选址 | Gurobi/SCIP/OR-Tools；覆盖率、容量、成本、失效情景 |
| 多级分配 | 最小费用流、多周期库存—运输联合优化 | 每期库存、缺货、浪费和总量平衡 |
| 配送路径 | CVRP/HVRP/VRPTW、ALNS、GA/SA | OSMnx/PyVRP/OR-Tools；逐路线容量/时间回代 |
| 地图与交付 | QGIS/GeoPandas/OSMnx + 参数化界面 | 道路距离、坐标系、可复算输入输出 |

## 写作和图表模板

- 摘要：影响证据 → 需求/配额 → 选址 → 路径 → 关键数量与验证，避免罗列全部算法缩写。
- 全篇总图按“数据层—决策层—执行层”画，清楚展示问题二/三如何为问题四提供节点和需求。
- 地图统一投影、道路与行政边界；节点颜色表示层级、大小表示容量，不同时编码太多变量。
- 物流网络图用三列固定上/中/下游，边宽表示流量，虚线表示备用路径。
- 路线结果除地图外，还要有车辆—载荷—里程—服务点—时间的核对表。
- 干预曲线标出政策时点、训练区、反事实区和置信带，不能只把两条线画在一起就称因果。
