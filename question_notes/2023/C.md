## 这类题的本质

它不是普通综合评价，而是“分配—评分校准—争议/创新识别—多阶段制度”的组合题。建模第一步是把公平、公正、可比、专业、创新分别操作化，并区分硬约束、软目标与历史制度偏好。

## 通用解题框架

1. 画利益相关者与流程：作品、专家、系统、复议委员会。
2. 建公平维度表：工作量、曝光、专业匹配、可比性、误判/漏判代价。
3. 把回避、每作评审数、每人工作量边界写成硬约束。
4. 把交叉均衡、匹配度、速度等写成可解释软目标。
5. 用小规模 MILP/CP-SAT 作精确标尺，大规模再用启发式。
6. 评分校准单独建模，保留原始分、标准分和不确定性。
7. 对历史回放、合成异常评委、极端作品和参数扰动做压力测试。

## 方法选择速查

| 任务 | baseline | 升级 |
|---|---|---|
| 专家—作品分配 | 随机/轮转 + 可行性修复 | 匹配、最小费用流、MILP/CP-SAT |
| 多目标分配 | 固定权重 | ε-constraint/Pareto/NSGA-II |
| 评委尺度差异 | z-score/稳健标准化 | 分层模型、Rasch/评委偏差模型 |
| 争议作品识别 | 极差/IQR/MAD 规则 | 有标签时树模型/异常检测 |
| 创新识别 | 独立创新评分或复议 | 不能仅用极差替代创新；需多源证据 |
| 制度评价 | 约束满足 + 历史回放 | 仿真、压力测试、群体公平与稳定性 |

## 写作和图表模板

- 摘要按“分配、评分、识别、完整制度”四问写，每问给指标含义而非只列算法。
- 第一章明确公平定义和制度目标；符号表按集合、参数、变量、指标分组。
- 用二分图画分配，用泳道图画制度，用分布/KDE/箱线图画校准前后，用排名迁移图画名次变化。
- 结果必须同时呈现效率和个体/群体差异，不能只给一个综合分。
