## 这类题的本质

这是“随机接入机理 + 非对称关系 + 性能核算 + 仿真验证”题。四问只改变两个关系：能否互听决定退避是否冻结，并发能否成功决定冲突/丢包。最稳妥的做法是先建立节点状态机，再由节点发送/失败概率核算系统吞吐，最后用离散事件仿真复核。

## 通用解题框架

1. 画关系图：载波侦听图与干扰图分开。
2. 定义状态：退避阶、计数器、发送、冻结、ACK、超时、重传上限。
3. 写转移：明确虚拟时隙长度与真实时间的换算。
4. 求稳态：得到发送概率、条件失败概率和重试分布。
5. 核算吞吐：有效载荷期望除以总时间期望，完整计入协议开销。
6. 仿真复核：优先队列推进事件，设置热身期、随机重复和置信区间。
7. 情景扫描：速率、包长、丢包、退避窗、RTS/CTS、拓扑逐项改变。

## 模型和工具选择

| 条件 | 方法 | 工具 |
|---|---|---|
| 对称、饱和、状态少 | Bianchi/Markov 闭式或数值解 | SymPy、SciPy `root`、MATLAB |
| 非对称拓扑 | 节点级方程 + 感知图/干扰图 | NetworkX + SciPy |
| 规则多、时序异步 | 离散事件仿真 | SimPy、自写事件队列、ns-3 |
| 参数不确定 | Monte Carlo、敏感性、区间 | NumPy/SciPy |
| 需要优化协议参数 | 解析筛选 + 仿真验证 | Optuna/贝叶斯优化或受约束优化 |

## 写作和图表模板

- 摘要：每问写“关系变化—模型修正—理论值—仿真值/误差”。
- 正文：场景图 → 状态机 → 方程 → 吞吐核算 → 仿真流程 → 结果对照。
- 图：感知图和干扰图分别用实线/虚线；状态图突出冻结和超时回环；结果用理论线 + 仿真点/置信带。
- 表：统一列出场景、参数、理论吞吐、仿真均值、标准差、相对误差和运行时间。
