## 这类题的本质

这是“核算—解释—预测—情景—路径”五层相连的长期规划题。历史数据回答“过去发生了什么”，驱动分解回答“哪些恒等因素共同形成变化”，预测给出延续趋势下的基准，情景表达政策和技术假设，路径优化才回答“怎样达到目标”。这五层不能被一个黑箱预测器替代。

## 通用解题框架

1. 固定核算边界：地区、部门、能源品种、直接/间接排放、基期和单位。
2. 用能源平衡与碳核算恒等式复算历史量，缺失值处理后仍要检查加总一致。
3. 用 Kaya/LMDI/STIRPAT 分清恒等分解、统计关联和因果政策杠杆。
4. 建立朴素趋势基线，再用滚动起点回测比较 ARIMA、回归、状态空间或机器学习。
5. 冻结“延续趋势”基准情景；政策情景只改有明确含义的增长率、强度、结构和碳因子。
6. 逐情景计算目标差距、资源约束、达峰年份及不确定区间。
7. 只有存在明确决策变量、边界和代价时才做路径优化；否则给条件性路线图而非伪最优解。
8. 形成年度监测指标、触发阈值和偏离目标后的调整规则。

## 模型和工具选择

| 子任务 | 首选方法 | 工具与注意点 |
|---|---|---|
| 历史核算 | 排放因子法、能源平衡表 | pandas；先做单位、部门加总和基期核验 |
| 驱动解释 | Kaya/LMDI、STIRPAT | LMDI 是恒等分解；STIRPAT 系数仍需统计假设 |
| 短样本趋势 | 线性/岭回归、ETS/ARIMA、状态空间 | statsmodels；滚动回测优先于训练期拟合度 |
| 多驱动预测 | 正则化回归、树模型、带外生变量时间序列 | scikit-learn；防止长期外推脱离约束 |
| 部门情景 | LEAP、系统动力学、情景树 | LEAP/Vensim/Stella；参数表必须可追溯 |
| 路径配置 | 线性/非线性规划、鲁棒/随机规划 | Pyomo/Gurobi；目标、约束和政策变量分开 |
| 不确定性 | 参数敏感性、蒙特卡洛、区间/情景包络 | 报告达标概率或范围，不只给单一 2060 数值 |

## 写作和图表模板

- 摘要按“核算与驱动—基准预测—情景设定—路径与监测”写，区分模型输出和人为情景参数。
- 第一章先给核算边界表和“事实层—预测层—情景层—决策层”总图，不把所有候选算法堆进一张路线图。
- 预测结果用“历史实线 + 回测段 + 未来区间”；情景图统一坐标并画政策目标线。
- 驱动贡献用瀑布图，能源结构用堆积面积图，关键参数用敏感性龙卷风图；少用多年份饼图。
- 情景参数表至少列基准值、变化规律、依据、可控性和不确定范围。
- 建议段落按“措施—改变的参数—预计方向/范围—监测指标—触发调整”组织。
