# 2024 D 题：暴雨成灾与土地利用时空分析

> 状态：`partial` 代表性阅读。已精读 1/4 篇（D24103850092）并核对关键 PDF 页面；其余 3 篇只完成摘要、模型路线和明显风险概览，仍保持 `pending`。本卡不是四篇深读后的频率统计。

## 赛题结构与代表路线

本题把多源时空数据串成四类任务：降水与土地利用演变描述、暴雨形成/影响因素分析、脆弱性评价及未来预测、土地利用空间方向与区域开发讨论。代表论文 D24103850092 的路线是“描述统计与地图 → 决策树 → 熵权指数 + XGBoost + ARIMA/SVR → 标准差椭圆与探索性分界线”。

真正的难点不在模型数量，而在四个接口：不同数据能否对齐到同一时空尺度；暴雨事件与年度背景是否混用；风险标签是否有独立灾损依据；未来预测是否按真实部署方式验证。

## 一篇精读得到的核心判断

1. 年均降水适合长期演变，不足以解释小时/日尺度暴雨触发；事件定义应依据当地标准和强度—历时—频率关系。
2. 空间格点随机拆分容易让邻近样本同时进入训练与测试，应改用区块/行政区留出；未来预测则用滚动时间回测。
3. 综合指数如果由输入变量加权生成，再用同一批变量训练模型，预测高分只说明能复现该指数，不能证明真实灾害风险。
4. 特征重要性、SHAP 或树分裂阈值是模型关联解释，不自动等于成灾因果或物理临界值。
5. 多阶段预测必须避免目标泄漏，并把上游时间序列的不确定性传播到最终风险区间。
6. 标准差椭圆适合概括二维方向和离散程度；一倍二维椭圆不能照搬一维正态 68% 规则，地图叠加也不能替代独立验证。

## 比赛可直接采用的工作流

1. 建立数据字典：坐标系、网格、时间尺度、单位、缺失和重采样规则。
2. 先做趋势、季节性、空间自相关和极端事件基线；画清“危险性—暴露度—脆弱性/承灾力”信息流。
3. 预测模型从可解释回归/树模型开始；只有残差、非线性或外推失败提供证据时才升级集成或深度模型。
4. 验证按声称的用途设计：空间外推用空间阻塞，未来外推用前推回测，真实风险用独立灾损标签。
5. 权重、阈值、重采样、空间分辨率和未来情景全部做敏感性分析；报告区间，不只给单点地图。

## 工具速查

- 栅格/矢量与地图：xarray、rasterio、GeoPandas、Shapely、pyproj、QGIS/ArcGIS。
- 时空统计：statsmodels、PySAL、Mann–Kendall/Theil–Sen；极值分析可用 SciPy 或专门的 EVT 包。
- 表格预测：scikit-learn Pipeline、XGBoost/LightGBM；用 GroupKFold、空间块或自定义时间切分器。
- 时间预测：statsmodels ARIMA/ETS、Prophet 仅作候选；必须与季节 naive/线性趋势 baseline 同口径回测。
- 风险指数：pandas/NumPy 实现透明加权；SALib 做敏感性；有真实标签时再用概率模型和校准曲线。
- 空间制图：颜色应可区分且色标、单位、时间、数据源完整；同一变量跨年份使用固定色阶。

## 写作模板

- 摘要：一句总目标；每问写“任务—方法—验证—最重要结果”；最后说明可用边界，不堆模型名。
- 第一章：背景只保留赛题所需事实；重述明确输入/输出；问题分析突出时空尺度、标签和验证难点；技术路线画数据流而非算法清单。
- 每问正文：数据与假设 → baseline → 缺陷证据 → 升级模型 → 时空留出验证 → 不确定性/边界 → 小结。
- 图表：地图统一投影、色阶与单位；预测图给真值对照、残差、分组误差和区间；风险分区同时展示阈值敏感性。
- 终稿审校：检查目标泄漏、时空切分、权重来源、指标口径、图文一致、地理名称、单位和政策措辞。
