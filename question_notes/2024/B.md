# 2024 B 题横向比较：WLAN 组网吞吐量建模

> 状态：`partial` 横向比较。已通读本仓库该题 4 篇论文正文至参考文献并抽查关键 PDF 页面；未复现代码，数值均为作者报告。

## 共同问题结构

四篇都可归纳为：拓扑/RSSI/门限 → AP 发送机会回归 → `(MCS,NSS)` 或 PHY Rate 预测 → 单 AP 与系统吞吐量预测。最可迁移的思想是利用通信机理构造门限相对特征、SINR、互听关系和合法速率映射，再由数据模型补足复杂非线性。

## 路线比较

| 模块 | 范文路线 | 更稳妥的选择规则 |
|---|---|---|
| RSSI 序列处理 | 插值到固定长度、均值/最大值、越门限比例、聚类状态 | 若只需工况统计，优先分位数、波动和越阈比例；只有明确依赖时序形态时才重采样/CNN，并做插值敏感性 |
| 发送机会 | 随机森林、GBDT/XGBoost、SVR、LSTM | 表格小样本先线性/树模型；LSTM 只用于有真实时间顺序的窗口。特征重要性不是因果效应 |
| MCS/NSS | 联合分类、分别分类、预测 PHY Rate 后映射 | 类别不平衡且组合受约束时，优先联合/层次分类或连续潜变量+合法投影；报告 macro-F1、各类召回和非法组合率 |
| 吞吐量 | 直接回归、级联预测、机理公式、机理特征+黑箱 | 先用量纲正确的机理基线，再比较直接回归与残差模型；级联必须用 out-of-fold 中间预测训练第二层并评估误差传播 |

## 本题暴露的高风险错误

1. dBm 不能直接做普通加法；干扰与噪声相加须先转线性功率，再换回 dB。
2. 先过采样后随机切分会让复制样本进入验证集，产生严重泄漏；所有填补、缩放、编码和重采样只在训练折拟合。
3. 同一 `test_id`、拓扑或实验文件中的相关样本应分组切分，不能逐行随机拆散。
4. 分类的高 Accuracy 可能只反映多数类；回归不要把 `1-MAPE` 笼统称“准确率”。
5. 聚类簇不能未经标签验证就命名为同步/异步物理状态；预测后加随机噪声也不是提高精度。

## 推荐比赛工作流与工具

1. 用 pandas 做字段审计，画拓扑/信息流并列出部署时可用特征。
2. 用 NumPy 正确转换 dBm↔mW，构造 SINR、越阈比例、干扰汇总、合法 PHY Rate 映射。
3. 用 scikit-learn `Pipeline` + `GroupKFold` 比较线性、随机森林、梯度提升；类别不平衡用 imbalanced-learn，但只作用于训练折。
4. 分类报告混淆矩阵、macro-F1、每类召回；回归报告 MAE/RMSE/MAPE/R²和误差经验 CDF，并按 2AP/3AP、协议、拓扑分层。
5. 若采用两阶段模型，用交叉拟合生成第一层训练预测，并和“直接预测吞吐量”“机理公式”“机理+残差”三条基线同折比较。

## 写作模板

- 摘要：三个问题分别写输入结构、最终选择、验证口径和一项代表性数值，不堆八九种候选模型。
- 第一章：画一张信息流图，明确发送机会和 PHY Rate 如何进入吞吐量；问题重述不提前写答案。
- 正文：把通信机理、特征工程、预测模型分开；结果表统一数据折和指标，正文只解释差异最大的现象。
- 图表：误差 CDF 横轴是误差阈值、纵轴 0—1；热力图变量过多时改用目标相关条形图；所有坐标含变量与单位。
