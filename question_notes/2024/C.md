# 2024 C 题横向比较：磁芯损耗建模

> 状态：`partial` 横向比较。已通读本仓库该题 4 篇论文正文至参考文献并抽查关键 PDF 页面；未复现代码，数值均为作者报告。

## 共同问题结构

四篇都形成“励磁波形识别 → Steinmetz 方程温度修正 → 温度/波形/材料影响分析 → 跨工况损耗预测 → 损耗与传输磁能双目标优化”的完整链条。前问不是孤立任务：波形标签、温度效应、材料差异和损耗预测器最终都要进入问题五。

本题最重要的选择原则不是追求最长模型名，而是先回答三件事：规则波形是否真的需要复杂分类器；经验式残差显示缺少了哪一项；最终验证是否覆盖新材料、新波形、新温度和频率外推。

## 四条建模路线的横向判断

| 模块 | 四篇范文中的路线 | 更稳妥的选择规则 |
|---|---|---|
| 波形分类 | 几何/统计/频谱特征 + RF/MLP/SVM/Stacking；HHT 边际谱与双谱抗噪特征 | 三类规则波形在随机划分上几乎都高度可分，先用阶跃数、峰度、峰值因子和谐波能量比建立规则或浅树 baseline。只有在噪声曲线、形变或跨材料测试显示退化后，才引入多域特征或 1D-CNN |
| SE 温度修正 | 对数线性化；温度线性、指数、幂式和多项式修正；温度交互；神经网络动态生成参数 | 先画残差随温度、`log f`、`log Bm` 的结构，再增加最少必要项。函数族在验证集选择，测试集只用一次；复杂动态参数应称为机理结构约束，而非稳定物理常数 |
| 因素分析 | 单/多因素 ANOVA、Kruskal-Wallis、Mann–Whitney U、分组均值和热点图 | 四篇普遍难点是没有同时控制频率和 Bm；显著性不能直接当净效应或因果。优先用 `log(loss)` 的 ANCOVA、含交互项回归、GAM 或分层模型，报告效应量、区间并校正多重比较 |
| 通用预测 | 12 个分组公式；CatBoost + IGSE 派生特征；卷积 + Bi-LSTM；动态参数经验式网络 | 表格数据先比较共享参数经验式、分组/层级模型、CatBoost/XGBoost；只有存在真实顺序时才用 LSTM。机理派生特征必须在训练折内估计；按材料、波形、温度、频率区间做分组留出 |
| 双目标优化 | 比值或加权减法标量化；GA、PSO、GWO；NSGA-II/MOPSO Pareto 路线 | 先统一目标方向与量纲，再决定要一个偏好点还是整条 Pareto 前沿。离散类别外层枚举，连续变量内层优化；每个结果必须回代所有边界，不能把越界点留在结果表中 |

## 可靠的比赛工作流

1. 数据审计：核对样本独立单位、三类波形数量、材料/温度/频率/Bm 覆盖范围和附件二是否有真值。
2. 问题一：规则/浅树 baseline → 分层或分组验证 → 多噪声强度压力测试 → 由退化证据决定是否升级特征。
3. 问题二：SE/LSE baseline → 残差诊断 → 候选温度项 → 独立验证选模 → 参数符号、逆变换和单位复核。
4. 问题三：先控制 `log f`、`log Bm`，再估计温度、波形、材料和交互；区分“显著差异”“效应大小”“工程最优”。
5. 问题四：使用同一数据折比较机理、树模型、机理增强和深度模型；预处理、派生机理参数和特征筛选全部放在训练折内。
6. 问题五：明确离散/连续变量和可行域；输出 Pareto 前沿或权重敏感性，并报告可行率、多随机种子、收敛性和最终回代检查。

## 四篇共同暴露的高风险问题

1. 随机逐行划分被写成“泛化能力”，但没有证明跨材料、跨波形、跨温度或频率外推。
2. 同一验证集反复承担模型、特征和超参数选择，使极高 R² 或极低相对误差偏乐观。
3. ANOVA/非参数检验常忽略频率和 Bm 混杂；“有差异”“影响最大”“因果作用”被混写。
4. t-SNE、特征重要性和热点图是探索/展示工具，不能单独证明可分性、因果或泛化。
5. 优化结果中出现温度/频率/Bm 越界、正文与表格冲突、权重行错位；群智能算法输出必须逐解验证。
6. 作者报告的高指标不能替代可复现流水线；本轮未运行四篇附录代码。

## 工具选择速查

- 数据与可视化：pandas、NumPy、Matplotlib/Seaborn；先画覆盖范围、残差、分组误差和目标空间。
- 分类/回归：scikit-learn `Pipeline` + `GroupKFold`；表格模型用 CatBoost/XGBoost，参数估计用 SciPy/statsmodels。
- 因素分析：statsmodels ANCOVA/含交互回归；非线性用 GAM；重复比较用 Holm/FDR；需要层级借力时用混合效应模型。
- 深度模型：PyTorch；仅在数据量、输入结构和消融实验支持时采用，且保留简单模型同折基线。
- 多目标优化：pymoo/NSGA-II；类别变量枚举或合法整数编码，比较 Hypervolume、IGD、可行率、运行时间和多次运行分布。

## 写作与格式模板

- 摘要：先给五问之间的主线，每问写“任务—最终方法—验证口径—一个代表性结果”；不要罗列所有候选算法，更不能把未通过约束复核的解写入摘要。
- 第一章：问题重述只说明输入、输出和约束；问题分析解释前问如何给后问提供标签、参数、因素认识和预测器。
- 每问正文：baseline → 发现的缺陷 → 升级模型 → 同口径对照 → 误差/边界 → 小结。失败候选也可简写，体现模型选择是验证结果而非事后包装。
- 图表：分类给混淆矩阵和噪声曲线；回归给 y=x、残差及分组误差；因素分析给效应量和区间；优化给 Pareto 前沿、可行域和选点规则。图题、坐标、单位、图例应独立可读。
- 终稿审校：逐项核对“摘要—正文—公式—表格—结论—附件代码”，并自动断言 `RMSE≥MAE`、变量边界、类别编码和单位换算等可检验条件。
