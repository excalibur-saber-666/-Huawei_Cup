# 2024 A 题横向比较：风电场有功功率优化分配

> 状态：`partial` 横向比较。已通读本仓库该题 4 篇论文正文至参考文献并抽查关键 PDF 页面；未复现代码，数值均为作者报告。

## 共同问题结构

四篇都形成了相同的系统链：在线疲劳指标 → 功率/风速到载荷或损伤的代理模型 → 带功率平衡与单机边界的分配优化 → 噪声、延迟或缺失情况下的修复与再优化。

这类题的核心不是先挑算法，而是逐层定义接口：指标是否能实时更新、代理模型是否可外推、优化变量和真实控制量是否一致、数据修复是否因果、修复后是否重验所有约束。

## 路线差异与判断

| 模块 | 范文路线 | 可迁移结论 |
|---|---|---|
| 疲劳在线化 | 极值缓存、滑动/自适应窗口、Goodman-Miner、暂时损伤 | 计算加速和未闭合循环估计是两类问题；窗口法必须检查跨窗循环、重复计数和未来信息 |
| 载荷代理 | 物理公式、多项式/分段回归、BiLSTM | 先做时间对齐和残差诊断；小样本、强机理场景优先可解释回归，序列模型须证明窗口因果性 |
| 分配优化 | DDPG、NSGA-II、MPC+SLSQP、遗传算法 | 先识别数学结构。线性/凸问题用 LP/QP；滚动决策用 MPC；非凸黑箱或真实多目标冲突才用启发式/RL |
| 不确定性 | 区间鲁棒、卡尔曼/SVD 去噪、LSTM/样条补值、延迟补偿 | 去噪、缺失、延迟、最坏情形是不同问题；分别验证模块收益，并在修复后重算目标与约束 |

## 可靠验证模板

1. 指标层：与离线 rainflow 或可信实现对照，并分别报告误差、耗时和边界案例。
2. 代理层：按时间和机组留出；报告 MAE/RMSE/相对误差、y=x 散点和残差随工况变化。
3. 优化层：同时报告目标改善、总功率残差、逐机上下界、动作修复率、最差机组与公平性。
4. 扰动层：原始、受扰、修复、修复后优化四组消融；区分平均随机性能与严格最坏情形保证。

## 写作模板

- 摘要：每问用“任务结构—关键方法—验证口径—最有解释力的数值”一句，不列长串算法名。
- 第一章：题意和难点；说明前两问怎样为第三问提供指标/代理，第四问怎样修正闭环。不要把求解方案写进问题重述。
- 每问：问题分析 → 变量/假设 → 模型 → 求解器与参数 → 验证 → 小结与边界。
- 图表：总路线图只画模块接口；趋势图配局部放大和 y=x 散点；多目标给 Pareto 前沿及选点规则；图题、坐标、单位必须自洽。
