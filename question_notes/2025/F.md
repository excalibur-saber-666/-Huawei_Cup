# 2025 F 题：江南古典园林美学特征建模

> 状态：`partial` 代表性阅读。已精读 1/4 篇（2025-F-004）并核对关键 PDF 页面；其余 3 篇完成摘要、目录、模型路线与写作结构概览，仍为 `pending`。

## 这类题的本质

这不是简单的“综合评价题”，而是四类任务的组合：

1. 测量建模：把趣味性、幻境感等潜在概念转成可观察指标；
2. 空间与图建模：把平面要素变成通行域、路网、视域和局部空间单元；
3. 决策建模：在景观收益、路径长度和重复之间寻找折中；
4. 比较与验证：建立跨园林表征、相似度和外部案例证据。

拿题后先问“这个概念由谁、在什么尺度、通过什么过程感知”，再问“用什么算法”。趣味性是沿路径发生的动态体验，幻境感同时依赖局部元素组织和开合序列，相似度则需要前两问形成同口径表征。

## 通用解题框架

### 第一步：构建概念树

以“趣味性”为例：

```text
趣味性
├─ 景观变化：相邻视点景观组合/视域变化
├─ 路径节奏：转折、交叉、开合序列
├─ 探索性：覆盖、分支、选择机会
├─ 舒适与效率：长度、坡度、拥挤、重复
└─ 个体偏好：省时/观景/无障碍/亲子
```

每个叶节点都要对应数据和计算规则；没有数据支持的维度要删除、弱化或作为讨论项。

### 第二步：把平面数据变成合法几何对象

统一坐标、比例和单位；区分可通行面、道路中心线、障碍、可视遮挡和景观对象。用缓冲、相交、并集/差集、连通性和采样间距检查几何。通行障碍与视觉遮挡不是同一个对象，不能混用。

### 第三步：选择正确的分析单位

- 路线问题：节点、边、路径与沿途观察序列；
- 布局问题：规则网格、分区或视域多边形；
- 相似度问题：每座园林一个冻结口径的特征向量/图表征；
- 游客评价：游客 × 路线/空间的层级样本，需考虑个体差异。

### 第四步：先做最小 baseline

- 路径：最短路、最少重复路、几个预设权重方案；
- 评价：等权标准化加总；
- 分区：K-means/层次聚类；
- 相似度：标准化欧氏/余弦；
- 验证：官方路线或专家评分的留出对照。

只有当 baseline 的具体缺陷出现，例如空间碎片、忽略遮挡、排名对权重极敏感、单目标路线不可接受，再升级 MRF、视域分析、多目标优化或学习排序。

### 第五步：建立评价与优化接口

评分模型负责说明“什么是好”，优化模型负责在约束下寻找方案。先写清：

- 决策变量：选哪些边、节点或空间配置；
- 目标：观景收益、长度、重复、拥挤、无障碍等；
- 硬约束：通行、入口出口、时间预算、安全与不可穿越区域；
- 偏好：固定权重、ε-constraint 或 Pareto 前沿。

不要先决定“用遗传算法”。小图可用枚举、动态规划、MILP/CP-SAT 作精确标尺；大图或多目标再使用 NSGA-II、GA、局部搜索。

### 第六步：验证“指标测到了什么”

至少组合以下证据：

1. 几何/算法回代：路线合法、指标可复算；
2. 构念效度：指标与理论、专家或游客评价对应；
3. 对照效度：与官方方案、等权 baseline、简单聚类比较；
4. 稳健性：权重、阈值、网格、噪声、缺失和随机种子；
5. 外部效度：冻结模型后用于新园林/新人群；
6. 不确定性：报告分数区间、排名反转和 Pareto 候选。

## 模型选择速查

| 难点 | 首选 baseline | 何时升级 | 升级方法 |
|---|---|---|---|
| 路网提取 | 中心线/骨架 + 图 | 道路边界破碎、分支多 | Voronoi、形态学骨架、空间索引、几何修复 |
| 沿途可见景观 | 邻域元素计数 | 遮挡和视角影响显著 | 射线追踪、视域多边形、照片/视频特征 |
| 异景程度 | 相邻景观向量距离 | 既要变化幅度又要稀有性/序列 | Jaccard/Hamming、转移概率、DTW/序列熵 |
| 路线规划 | 最短路/加权最短路 | 多目标、重复与覆盖冲突 | ε-constraint、MILP、NSGA-II、GA |
| 空间分区 | K-means/层次聚类 | 结果碎片且空间连续性重要 | GMM-MRF、谱聚类、区域生长 |
| 综合评分 | 等权加总 | 专家偏好或信息差异有证据 | AHP、熵权/CRITIC、模糊评价、贝叶斯标定 |
| 园林相似度 | 标准化欧氏/余弦 | 数据混合连续、集合、图结构 | Gower、Jaccard、多核、图核/图嵌入 |
| 外部验证 | 新对象直接运行 | 有独立专家/游客标签 | 有序回归、学习排序、层级贝叶斯、多任务模型 |

## 工具选择

- 几何与 GIS：Shapely、GeoPandas、Rasterio、QGIS；
- 图与路径：NetworkX、OSMnx、OR-Tools、Pyomo/PuLP；
- 图像/骨架/视域：OpenCV、scikit-image，自定义射线追踪；
- 聚类与评价：scikit-learn、SciPy、statsmodels；
- 多目标优化：pymoo、DEAP；
- 可视化：Matplotlib/Seaborn/Plotly，GIS 底图与路线叠加。

四天赛程优先选团队能解释、能运行、能做对照的工具。若没有可靠标签和算力，不要让 NeRF、深度多模态或复杂图网络挤占指标论证与验证时间。

## 写作模板

### 摘要

首句写清“传统美学概念主观、平面/坐标数据客观，两者之间缺少可计算接口”。每问用一段：任务对象 → 如何操作化 → 核心模型 → 对照/稳健性 → 输出。避免只罗列 AHP、遗传算法、聚类等名词。

### 每问正文

1. 概念定义与观察尺度；
2. 数据对象和分析单位；
3. 代理量为何代表概念；
4. baseline 与具体不足；
5. 升级模型、目标/约束或权重；
6. 结果地图/表格；
7. 对照、敏感性和边界；
8. 给下一问的中间量。

### 图表

- 平面图：底图浅灰，同类要素固定颜色，路线高对比；必须有比例尺、入口出口和方向；
- 流程图：每个框写输入/输出，不只写算法名；
- 热力图：颜色有物理含义并注明尺度；
- 相似度矩阵：对象顺序与聚类一致，数字保留合理位数；
- 排名表：同时给分维度分数、总分和不确定性；
- 敏感性图：横轴明确参数/扰动范围，画出合格阈值或排名反转。

## 最重要的写作认识

主观题也可以严谨，但严谨不是把主观判断隐藏在复杂公式里。应公开概念选择、指标代理、权重来源和价值判断，再用对照、扰动、外部案例和不确定性说明结论能支持到什么程度。
