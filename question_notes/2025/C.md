# 2025 C 题：围岩裂隙识别与三维重构

> 状态：`partial` 代表性阅读。已精读 1/5 篇（2025-C-005）并核对关键 PDF 页面；其余 4 篇只完成摘要、目录、模型路线和写作结构概览，仍为 `pending`。

## 拿到这类题应该怎样思考

这类题不是单纯的图像分割题，而是一条“观测 → 对象 → 参数 → 空间结构 → 决策”链：

1. 在纹理、泥浆和钻进痕迹中找到裂隙像素；
2. 把断续像素重组为一条条裂隙实例；
3. 提取正弦趋势、粗糙度等可解释参数；
4. 把多个钻孔的二维曲线反演成三维结构面并估计连通性；
5. 明确哪些区域“看不清”和哪些区域“没看见”，再安排补充钻孔。

最重要的抽象是对象层级。每升一级，都要问：上一层输出是否足以支撑本层任务、误差怎样传播、物理约束是什么。深度学习适合像素层，不代表曲线拟合、三维重构和选址也应继续使用神经网络。

## 模型选择决策树

### 1. 先确认是否有可靠像素标签

有足够标签、背景变化大时，使用 U-Net/DeepLabV3+；目标占比极低时加入 Dice/Focal。标签不足时，以 Frangi、Canny、Otsu、局部纹理和形态学建立可解释 baseline，必要时采用多方法投票或连通域特征二次筛选。两条路线都应保留少量人工核对集。

### 2. 像素掩码是否已经等于单个对象

通常不等于。先做连通域、骨架和中心线，再判断实例数量未知、形状不规则且含噪时是否使用 DBSCAN/HDBSCAN。若同一裂隙被切成碎片，应加入正弦/轨迹等几何先验，用 RANSAC 或“拟合—吸收—重拟合”完成模型驱动聚类。

### 3. 目标参数属于宏观趋势还是微观波动

振幅、周期、相位、中心线描述宏观趋势；JRC 描述相对基准面的微观起伏。先拟合并去除低频趋势，再计算粗糙度。曲线非正弦时可用傅里叶、小波、样条或多尺度残差，但复杂度必须由拟合残差和物理需求触发。

### 4. 采样会不会改变结论

会。画“采样点数—JRC/误差”收敛曲线，比较等横坐标、等弧长、曲率自适应和关键点采样；有标准轮廓、合成曲线或人工真值时优先做外部验证。不要只挑一个点数后给结果。

### 5. 二维截面能否唯一确定三维网络

通常不能。先写清坐标变换和结构面假设，再用参数分布、Bootstrap 或 Monte Carlo 传播误差。连通性可由距离、姿态、深度、粗糙度等构成相似度或概率，但权重和阈值需要校准与敏感性分析。

### 6. 三维结果如何转成工程行动

把裂隙作为节点、候选连接作为边，用连通分量或社区发现识别网络；再把不确定性分为关系模糊和空间空白。前者对应验证性观测，后者对应探索性观测。采用序贯设计：新增一个/一批钻孔后更新网络，再决定下一步，而不是一次性给出静态点位。

## 通用建模流程

1. 建立坐标与单位字典，确认图像展开方向、钻孔直径、像素分辨率和孔口位置。
2. 建立传统视觉 baseline，并制作少量人工标签作为统一比较集。
3. 选择传统或深度分割；报告像素、实例和中心线三层指标。
4. 掩码清理、骨架提取、实例聚类；用形状先验补全碎片并拟合参数。
5. 去除宏观趋势，在标准轮廓/合成数据上选择 JRC 采样策略。
6. 二维参数转三维平面，传播参数不确定性，构建概率图并分析阈值稳定性。
7. 绘制不确定性地图，将“验证”和“探索”分开评分，滚动选择补充钻孔。
8. 回代检查单位、坐标、几何边界和前后问对象 ID；导出可复核的参数表与图。

## 工具选择

- 图像处理：OpenCV、scikit-image；Frangi、CLAHE、Otsu、形态学、骨架化和连通域。
- 深度分割：PyTorch、segmentation-models-pytorch、Albumentations；小样本优先迁移学习。
- 聚类与拟合：scikit-learn DBSCAN/HDBSCAN，SciPy `least_squares`，RANSAC。
- 多尺度几何：NumPy/SciPy FFT、小波工具 PyWavelets、样条与曲率计算。
- 不确定性：Bootstrap、NumPy Monte Carlo、PyMC；参数少时先用可解释抽样。
- 网络与优化：NetworkX；候选点少用枚举/贪心，连续选址用 SciPy optimize，复杂多目标再考虑进化算法。
- 三维与图表：PyVista/Plotly 做可旋转三维核查，Matplotlib/Seaborn 输出论文静态图。

## 写作模板

### 摘要

第一句交代“强噪声图像 + 有限钻孔反演三维网络”的核心矛盾。之后每问一段，写清对象层级、为何选该模型、最关键的结果/验证，以及输出如何进入下一问。结尾写工程决策和不确定性，不要只罗列算法名。

### 正文

1. 在总技术路线图中画出像素、实例、曲线参数、结构面、网络和孔位六级对象。
2. 每问按“上一层不足 → 本问任务 → baseline → 升级理由 → 结果与验证 → 下一问接口”展开。
3. 坐标变换、单位与对象 ID 单独成表；公式后解释参数的几何或工程含义。
4. 分割、拟合、三维和选址分别给对应证据，避免用一个最终效果图替代中间验证。
5. 局限部分重点说明标签、形状假设、经验权重和三维欠定性，提出可执行的改进。

### 图表

- 原图—标签—预测三联图：证明识别；
- 掩码—碎片—拟合—重组四联图：证明对象化；
- 残差/采样收敛/标准轮廓：证明 JRC 方法；
- 参数表带单位和误差：支撑二维到三维；
- 三维钻孔—结构面—网络图：说明空间结构；
- 连通阈值敏感性和不确定性热图：说明稳健性与选址；
- 补孔前后信息增益表：说明决策价值。

## 从本题提炼出的通用思维

1. 先定义对象层级，再为每一层选择模型；不要让一个模型跨越所有层。
2. 结构先验既可作 baseline，也可用于修复数据模型输出。
3. 多尺度指标必须先分离趋势与残差，采样策略本身需要验证。
4. 从少量截面升维属于逆问题，应输出概率与不确定性，而不是唯一“真相”。
5. 不确定性只有映射成下一次观测或行动才真正有工程价值。
6. 四问论文应写成一条信息链，上一问的输出接口就是下一问的开头。
