# 2025 B 题：MIMO-OFDM 链路速率预测

> 状态：`partial` 代表性阅读。已精读 1/3 篇（2025-B-003）并核对关键 PDF 页面；其余 2 篇只完成摘要、目录、建模路线和写作结构概览，仍为 `pending`。

## 拿到这类题应该怎样思考

这不是单纯的“选一个回归器”。完整问题链是：

1. 把复数 CSI 与底噪转换成每个子载波的物理质量指标；
2. 从 122 个子载波压缩或提取可解释特征；
3. 建立等效信道质量到离散有序速率的映射；
4. 正确处理设备、文件、时间和 TxBF 场景之间的分布差异；
5. 用符合部署方式的分组验证选择模型，再预测无标签数据。

最稳的建模顺序是“物理 baseline → 残差诊断 → 特征增强/机器学习 → 分组验证 → 校准与不确定性”，而不是直接把 CSI 展开后训练复杂网络。

## 模型选择决策树

### 1. 首先做物理 baseline

如果题目给出 CSI、底噪和 EESM 公式，先严格实现 EESM，并用网格搜索/优化算法拟合少量参数。它是全题的可解释标尺，也是检查单位和数据解析是否正确的最好工具。

### 2. 映射应单调但形状未知时

使用 Isotonic Regression。它适合“信道质量提高，速率原则上不下降”的关系；比高阶多项式更稳，也能用于模型输出的后置校准。若需要平滑外推，可考虑单调样条或带单调约束的 GBDT。

### 3. EESM 误差与频域形状有关时

先增加分位数、IQR、深衰落比例、频域斜率、粗糙度、分段 EESM 和 SVD 特征，再用 HGBR/LightGBM/XGBoost。只有简单特征仍不足且样本量充足时，再考虑 1D-CNN、Transformer 或 SetTransformer。

### 4. 高维表格关系复杂但时间有限时

随机森林是可靠强 baseline：实现快、对缩放不敏感、能处理交互；HGBR 通常更节省内存并可加入单调约束。两者均需分组交叉验证，不能用训练拟合指标选模型。

### 5. TxBF 改变空间结构时

用 SVD 的奇异值、条件数、成形增益描述空间通道；不要只在旧模型上增加一个 TxBF 二值变量。可为 TxBF 开/关分别建模，也可共享物理特征后加入场景交互。

### 6. 训练域和预测域不同但目标域无标签时

先比较特征分布和物理统计量，再考虑中位数/IQR 对齐、CORAL 或重要性加权。域对齐只能说明分布更接近，不能替代目标域精度标签；模型选择仍应来自源域留组或模拟域偏移验证。

### 7. 真实决策关心“不要选得过高”时

使用分位数回归、保形预测或代价敏感损失，输出保守速率和置信区间。普通 RMSE 最小不一定等于链路决策风险最小。

## 通用建模流程

1. 定义样本独立单位、预测时刻和可用特征；按 MAC/文件/时间组设计切分。
2. 解析复数 CSI，统一功率、dBm/W、每子载波噪声和天线维度。
3. 建 EESM + 单调映射 baseline；保存 OOF 预测和逐组指标。
4. 画残差对等效 SINR、底噪、设备、分位数、SVD 特征的关系。
5. 只对有结构的残差加入统计/SVD/频域特征，再训练树模型。
6. 用 OOF 完成堆叠、融合和校准；使用递进消融表选择最终模型。
7. TxBF 场景重新计算物理特征，比较独立建模、共享模型和域适配。
8. 最终输出连续预测、最近档位、Top-1/±1、置信区间和异常标记。

## 工具选择

- 数据解析：pandas、openpyxl、NumPy complex arrays。
- 物理计算：NumPy/SciPy，`numpy.linalg.svd`。
- 参数标定：SciPy optimize、网格搜索、Optuna；参数少时优先可解释搜索。
- 机器学习：scikit-learn 的 Isotonic、GroupKFold、RF、HGBR；LightGBM/XGBoost 作为增强。
- 不确定性：分位数回归、MAPIE/自写 split conformal。
- 图表：Seaborn/Matplotlib，重点画分组分布、残差、校准、混淆矩阵和消融图。

## 写作模板

### 摘要

首段说明“高维 CSI 无法直接对应实际速率”的核心矛盾；之后每问一段，写清场景、物理特征、模型升级和 OOF/留组指标；结尾说明方法如何用于资源调度。避免只列模型名称。

### 正文

1. 数据与评价协议要早于复杂模型：先讲样本单位、分组和部署场景。
2. 每问按“物理 baseline → 观察到的不足 → 新特征/新模型 → 分组验证 → 结论”写。
3. 问题二、三复用问题一的符号和数据管线，只解释新增部分。
4. 单独设置消融表，证明每个模块带来的增量，不靠模型复杂度说明先进性。
5. 模型评价区分：物理合理性、预测精度、跨组泛化、计算开销和部署风险。

### 图表

- CSI/SINR 分布：说明场景和组间差异；
- EESM 参数扫描：说明参数选择和稳定区间；
- 等效 SINR—速率图：说明单调主趋势；
- 残差图：说明为什么升级模型；
- 消融表：说明各模块增量；
- 混淆矩阵：说明错误是否集中在相邻档；
- 校准图/预测区间：说明决策可靠性。

## 从本题提炼出的通用思维

1. 物理公式不是机器学习的对手，而是强 baseline、特征生成器和约束来源。
2. 复杂模型应学习 baseline 的残差，而不是重新学习全部物理关系。
3. 数据切分方式属于模型的一部分；错误的随机切分会让任何高级算法失去意义。
4. 标签既连续又有序离散时，要同时按数值误差和决策档位评价。
5. 融合权重、消融和 OOF 结果决定是否保留复杂模块；没有增益就回到简单模型。
6. 无标签目标域只能做预测与稳定性检查，不能用预测分布证明真实准确率。
