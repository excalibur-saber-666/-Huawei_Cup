# 赛题级横向比较卡

本目录用于比较同一年、同一题下多篇优秀论文：共同任务结构、不同建模路线、数据处理、验证证据、写作组织和可迁移思想。

## 证据规则

- 只有经过论文正文核对的内容才能写入题级卡；不得根据题名或文件名猜测。
- 单篇已核对案例只能称为“基础卡”，不能冒充多篇横向统计。
- 每个具体判断必须链接到 source_md；公式、复杂表格、图像和页码仍回看 PDF。
- pending 经验卡只表示等待审阅，不能作为已确认案例。
