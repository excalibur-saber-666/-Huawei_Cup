# 数学建模题型—解法—模型运用总指南

> 用途：比赛现场根据问题结构选择解法，并知道常见模型怎样落地、怎样验证、什么时候不该用。依据 [2022—2025 年 24 道赛题代表样本](ANNUAL_QUESTION_EVIDENCE_MATRIX.md)及已完成的题级精读整理。它不是“题型对应唯一算法”的答案表，也不代表 145 篇论文的方法频率统计。

## 一、先判断任务，不要先挑算法

拿到每一问，先填写六个空：

```text
输入是什么？
→ 输出是数值、类别、分组、参数、路径、排程还是方案？
→ 独立对象是谁，预测/决策发生在什么时点？
→ 哪些变量可控，哪些约束不能违反？
→ 最简单可信的 baseline 是什么？
→ 要用什么证据说明结果可信？
```

再识别数据结构：

| 结构信号 | 优先考虑 |
|---|---|
| 明显时间顺序 | 时间序列、状态空间、滚动验证；不能随机打乱 |
| 坐标、地图、邻接关系 | GIS、空间统计、图模型、空间分块验证 |
| 波形、振动、雷达、声音 | 频域/时频/物理特征，再考虑深度网络 |
| 图像、掩膜、目标 | 传统视觉 baseline、分割/检测、对象级后处理 |
| 守恒、动力学、协议规则 | 机理方程、状态机、仿真或机理—数据混合 |
| 明确资源、容量、顺序、时间窗 | LP/MILP/CP-SAT、网络流、动态规划、调度 |
| 无标签但要发现群体 | 聚类、异常检测；结论必须检查稳定性和业务意义 |
| 多个相互冲突目标 | Pareto、ε-constraint、目标规划；不要只给任意加权和 |
| 训练与应用场景不同 | 分组验证、域偏移诊断、迁移/域适应 |
| 输入或未来高度不确定 | 区间、Monte Carlo、情景、鲁棒/随机优化 |

## 二、题型与解法总表

| 题型 | 最小可信解法 | 常见升级模型 | 怎样运用 | 最少验证 | 常用工具 |
|---|---|---|---|---|---|
| 描述统计与影响因素 | 分布、散点、Pearson/Spearman | 检验、回归、PCA、树重要性、空间统计 | 先描述效应和不确定性，再控制混杂；关联不写成因果 | 效应量、区间、多重检验、子样本稳定性 | pandas、SciPy、statsmodels |
| 回归与连续量预测 | 均值、线性/岭回归、经典经验式 | 非线性回归、SVR、RF/XGBoost、机理残差学习 | 划分后在训练集做预处理；用残差决定是否升级 | MAE/RMSE、残差、区间、分组/外部测试 | sklearn、statsmodels |
| 时间序列预测 | 上一期、季节朴素、移动平均 | ETS/ARIMA、状态空间、树模型、TCN/LSTM/Transformer | 按时间前向切分；分别预测不同提前量 | 滚动回测、残差自相关、区间覆盖、漂移 | statsmodels、sktime、PyTorch |
| 分类与风险预测 | 多数类、规则、Logistic、浅树 | SVM、RF/XGBoost、CNN/Transformer、代价敏感学习 | 先定义标签和误判代价；输出概率时做校准 | 混淆矩阵、F1/PR-AUC、校准、对象级切分 | sklearn、LightGBM、PyTorch |
| 故障诊断 | 物理阈值、统计量、Logistic/SVM | 包络/阶次+树模型、1D-CNN、域适应 | 先按特征频率或阶次对齐，再分类；按原始文件/工况划分 | 跨工况测试、混淆矩阵、消融、未知类拒识 | SciPy、librosa、sklearn、PyTorch |
| 聚类与分群 | K-means、层次聚类 | GMM、DBSCAN、谱聚类、DTW/k-shape | 先定义距离与尺度；用多初始化/重采样检查簇是否稳定 | Silhouette/DBI/CH、稳定性、领域解释 | sklearn、tslearn |
| 综合评价与排名 | 等权标准化加总 | AHP/德尔菲、熵权/CRITIC、TOPSIS、PCA/因子、模糊评价 | 先定义概念维度和不可补偿底线，再定权和排序 | 权重扰动、留一指标、排名反转、外部准则 | NumPy、pandas、AHP/TOPSIS 自写 |
| 组合优化与调度 | 现行规则、贪心、小规模穷举/松弛 | LP/MILP、CP-SAT、DP、局部搜索、GA/SA/PSO | 先写变量、目标、硬约束；小规模精确解作标尺 | 可行性回代、上下界、运行时间、多种子 | OR-Tools、Pyomo、Gurobi |
| 多目标优化 | 单目标极值、固定权重基线 | ε-constraint、目标规划、Pareto、NSGA-II | 先统一量纲与方向；生成前沿后再说明选哪一点 | 前沿覆盖/收敛、权重偏好、可行性 | pymoo、Pyomo、Gurobi |
| 图论、路径与物流 | Dijkstra、MST、最近邻 | A*、网络流、TSP/VRP、时变/鲁棒路径 | 明确节点、边、方向、容量、时间窗和代价 | 成本复算、连通/容量检查、扰动与运行时间 | NetworkX、OR-Tools |
| 信号与时频分析 | 原始统计量、FFT、简单滤波 | STFT、小波、包络、EMD/VMD、MUSIC/ESPRIT | 采样率和物理频率先对齐；特征服务于定位/分类任务 | 合成/参考信号、SNR 扫描、频率/定位误差 | SciPy、PyWavelets、MATLAB |
| 图像识别与重构 | 阈值、边缘、形态学、连通域 | U-Net/DeepLab、YOLO、关键点、几何/三维重构 | 从像素转成对象和物理参数；每层单独验证 | IoU/Dice/mAP、对象误差、跨场景、误差传播 | OpenCV、PyTorch、scikit-image |
| 参数反演与逆问题 | 最小二乘、矩估计 | 正则化、稳健损失、贝叶斯反演、滤波 | 先查可辨识性；用合成数据验证能否找回真值 | 合成回收、区间、初值敏感性、物理范围 | SciPy、lmfit、PyMC |
| 机理、状态与仿真 | 经典方程、守恒、低阶近似 | ODE/PDE、Markov/排队、状态空间、离散事件/Agent | 先定义状态、时间和边界；仿真复现规则而不是代替解释 | 量纲、极限、小例子、步长收敛、实测/独立实现 | SciPy、SimPy、MATLAB、COMSOL |
| 多源融合与同化 | 单源模型、简单加权/拼接 | Kalman/EKF/EnKF、贝叶斯融合、特征/决策融合、变分同化 | 先做时空对齐和单源基线，再逐源加入 | 去源消融、对齐误差、冲突/缺失场景、校准 | xarray、FilterPy、PyTorch |
| 空间数据与 GIS | 最近邻、IDW、无空间项回归 | Kriging、空间回归、点过程、图/时空模型 | 统一投影、分辨率和支持尺度；避免随机点划分泄漏 | 空间分块验证、残差空间相关、尺度敏感性 | GeoPandas、PySAL、QGIS、ArcGIS |
| 迁移学习与域适应 | 不迁移模型、简单校准 | 微调、CORAL/MMD、DANN、伪标签 | 先证明域偏移，再比较“无迁移”；无目标标签时控制结论强度 | 目标域真值或受控替代、负迁移、类条件结构 | PyTorch、adapt、sklearn |
| 情景分析与长期规划 | 基准趋势情景 | 驱动变量情景、系统动力学、LEAP、鲁棒/随机规划 | 区分历史事实、基准预测、政策假设和决策变量 | 情景依据、参数表、目标差距、跨情景稳健性 | statsmodels、Vensim、LEAP、Pyomo |
| 不确定性与鲁棒决策 | 单因素扰动、标称方案 | bootstrap、Monte Carlo、情景树、鲁棒/随机优化、CVaR | 识别数据、参数、模型和未来情景四类不确定性 | 区间覆盖、样本外可行率、尾部风险、保守度 | NumPy、SciPy、Pyomo |
| 纯数学与算法构造 | 小规模解析、穷举 | 定理、分解、DP、数值优化、近似算法 | 先利用对称、递归、稀疏、凸性等结构，再用通用求解器 | 正确性证明、小例子、误差界、复杂度、规模扩展 | SymPy、NumPy、CVXPY |

## 三、常见模型怎样选择和使用

### 1. 线性回归、岭回归、Lasso

适合：连续输出、样本不大、需要解释或作为 baseline。

使用顺序：

1. 画散点和分组分布，处理单位与明显异常；
2. 只在训练数据上做编码和标准化；
3. 线性回归检查残差、异方差和共线性；
4. 共线性严重时用岭回归；需要稀疏筛选时可用 Lasso/Elastic Net；
5. 报系数区间和样本外误差，不用高 R² 代替外推证据。

不适合：关系明显分段/饱和却不做变换；类别编码错误；把系数直接解释成因果。

### 2. Logistic、SVM、随机森林、XGBoost

| 模型 | 什么时候优先 | 落地重点 | 常见问题 |
|---|---|---|---|
| Logistic | 小样本、概率风险、需要方向解释 | 正则化、类别权重、校准、优势比区间 | 漏掉非线性/交互；系数写成因果 |
| SVM | 中小样本、高维、边界复杂 | 标准化；在训练折内调 `C` 与核参数 | 测试集调参；概率未校准 |
| RF | 表格非线性、交互、少预处理 | 分组 CV、树深限制、置换重要性 | 不纯度重要性偏差；外推能力弱 |
| XGBoost/LightGBM | 表格预测、非线性较强 | 学习率/深度/早停；公平基线；SHAP 仅解释模型 | 小样本过调参；随机行划分泄漏 |

类别不平衡时先明确误判代价。过采样、SMOTE、特征选择和标准化必须放在训练折内部；指标优先 PR-AUC、Recall、Precision、F1 和校准，而不是只报 Accuracy。

### 3. ARIMA、ETS、状态空间、LSTM/TCN/Transformer

- 数据短、趋势/季节清晰：先用季节朴素、ETS、ARIMA。
- 状态不可直接观测、观测有噪声或需在线更新：状态空间/Kalman。
- 有多个外生变量：ARIMAX、动态回归、树模型的滞后特征。
- 数据量足、非线性长依赖明显：TCN/LSTM；更大规模再考虑 Transformer。

正确流程是“按时间排序 → 设预测时点和跨度 → 滚动起点回测 → 与朴素基线比较 → 检查残差与漂移 → 给区间”。不能用随机 K 折验证未来预测，也不能只在完整历史上拟合一次后报告训练误差。

### 4. K-means、GMM、DBSCAN、谱聚类

- K-means：近似球形、规模相近、欧氏距离有意义；先标准化，多初始化。
- GMM：簇可重叠、需要软概率；比较协方差形式和 BIC/AIC。
- DBSCAN：密度簇和噪声点；`eps` 与尺度敏感，先画 k-distance。
- 谱聚类：非凸形状但样本不能太大；相似度图的构造决定结果。
- 轨迹聚类：优先 DTW/k-shape/混合效应，不要把不等长随访粗暴拼成普通表格。

聚类不是“算出轮廓系数就完成”。必须检查不同初始化、距离、样本扰动下标签是否稳定，并给新样本可执行的归类规则。

### 5. AHP、熵权/CRITIC、TOPSIS、PCA

这些方法处理的不是同一件事：

- AHP/德尔菲：表达专家偏好，需一致性与专家来源；
- 熵权/CRITIC：利用样本差异或冲突定权，不等于客观价值；
- TOPSIS：按距理想点远近排序，依赖标准化、方向和权重；
- PCA/因子：降维或构造统计潜变量，不自动代表业务重要性。

推荐流程：定义概念 → 指标维度 → 指标方向/适宜区间 → 去冗余 → 等权 baseline → 定权/聚合 → 权重扰动、留一指标、排名反转 → 外部准则验证。安全、伦理或硬门槛不能被其他高分完全补偿，应使用门槛、规则或乘法效用。

### 6. LP/MILP、CP-SAT、动态规划、启发式算法

先写数学模型，再挑求解器：

```text
集合与索引
→ 决策变量及单位
→ 目标函数
→ 硬约束
→ 变量范围/整数性
→ 可行 baseline
→ 小规模精确标尺
→ 大规模求解
```

- 连续线性：LP；含 0-1/整数选择：MILP；
- 离散逻辑、排程、可满足约束多：CP-SAT；
- 明确阶段和状态转移、规模可控：动态规划；
- 图上的容量/匹配/运输：网络流或最小费用流；
- 精确法超时后才使用 GA/SA/PSO/局部搜索，并保留精确小例子作标尺。

启发式结果应报告多随机种子分布、运行时间和可行率；“找到最好值”不能写成“证明全局最优”。

### 7. Dijkstra、A*、TSP/VRP

- 单源最短路且边权非负：Dijkstra；有可靠启发函数：A*；
- 连接全部节点且不要求成环：MST；
- 访问顺序和回路：TSP；带车辆容量、时间窗、多个仓库：VRP；
- 风险随时间变化：时间扩展图、滚动规划或鲁棒路径。

路径前先定义边是否可达、方向、距离/时间/风险单位和硬禁区。输出后逐段复算总成本、容量、时间窗和连通性。

### 8. FFT、STFT、小波、包络与阶次分析

- FFT：稳定周期和频率成分；
- STFT：局部频率随时间变化，但窗长控制时频分辨率；
- 小波/CWT：冲击和多尺度瞬态；
- 包络谱：调制故障和轴承特征频率；
- 阶次分析：转速变化时将频率归一到转速；
- MUSIC/ESPRIT：阵列参数估计，需核查源数、阵列模型和相干性。

先给采样率、奈奎斯特范围、滤波带宽、窗函数和物理特征频率，再把特征送入分类器。漂亮的时频图不是验证；需要合成信号、SNR 扫描或已知故障频率对照。

### 9. U-Net、YOLO 与几何重构

- U-Net/DeepLab：像素级分割；
- YOLO：目标框/类别与实时检测；
- 传统阈值、边缘、形态学：应作为 baseline，也适合数据很少的题；
- 分割后通常还要连通域、骨架、曲线/平面拟合，把像素转成工程对象；
- 三维重构是新的逆问题，不能把二维高 IoU 直接当三维正确。

训练/测试应按原图、地点或对象分组，不能让同一大图裁片跨集合。除 IoU/Dice/mAP 外，还应验证对象数量、长度、角度、位置和下游决策误差。

### 10. ODE/PDE、Markov、排队与离散事件仿真

- 有守恒、增长、扩散或动力学：ODE/PDE；
- 状态随机转移且近似无记忆：Markov；
- 到达—服务—等待：排队模型；
- 规则异步、资源竞争、事件复杂：离散事件仿真；
- 长期反馈和政策回路：系统动力学。

建模顺序是“实体与状态 → 时间/事件 → 转移或方程 → 参数 → 指标”。至少做量纲、边界、极限、小规模手算、步长/仿真时长收敛和独立数据/实现对照。理论与仿真共享同一假设时，只能说明实现一致。

### 11. Kalman、贝叶斯融合与多源深度融合

多源题先解决校准，而不是直接拼接：

```text
坐标与时间统一
→ 分辨率/单位统一
→ 单源模型与误差
→ 观测噪声或可信度
→ 融合模型
→ 去源消融与故障场景
```

- 线性高斯动态系统：Kalman；非线性可考虑 EKF/UKF；集合方法可用 EnKF；
- 先验与观测不确定性可表达：贝叶斯融合；
- 大量多模态样本：早期拼接、特征级注意力或决策级集成；
- 空间连续场：变分同化、Kriging 或物理正则重构。

“融合后分数更高”不够；应比较每个单源、逐源加入、去源、错位、缺失和冲突场景。

### 12. Monte Carlo、鲁棒优化与随机优化

- 参数分布可估计：Monte Carlo/随机优化；
- 只知道上下界或集合：鲁棒优化；
- 关注尾部损失：CVaR；
- 政策未来存在多个可能世界：情景树/情景规划；
- 只想评估采样误差：bootstrap。

先列不确定来源及范围，再决定传播方式。报告分布、区间、最坏情形、样本外可行率和性能—保守度，而不是只做 ±10% 的装饰性扰动。

## 四、复合赛题怎样串联

多数研究生数模题不是单一题型，而是五层链条：

```text
数据层：清洗、对齐、采样、坐标与单位
↓
表征层：特征、指标、物理参数、状态
↓
认知层：分类、回归、聚类、预测、反演
↓
决策层：评价、排序、优化、路径、调度
↓
可信层：对比、区间、鲁棒性、泛化、解释
```

每个接口要记录：输入、输出、单位、适用时点、不确定性，以及前一层错误如何影响下一层。典型跨年路线包括：

- 信号 → 参数估计 → 轨迹：2022 A；
- 排样/调度结构 → 精确模型 → 启发式：2022 B/C/D、2025 A；
- 指标/预测 → 情景 → 决策：2022 E/F、2023 D；
- 状态机 → 理论吞吐 → 事件仿真：2023 A；
- 患者时间轴 → 风险 → 轨迹 → 预后：2023 E；
- 图像 → 对象 → 几何 → 三维网络 → 决策：2025 C；
- 多源观测 → 连续场 → 预测 → 风险路径：2025 D；
- 物理特征 → 源域分类 → 域适应 → 解释：2025 E。

具体证据与边界见 [赛题证据矩阵](ANNUAL_QUESTION_EVIDENCE_MATRIX.md)和 [同题比较卡](../question_notes/README.md)。

## 五、模型升级的判断标准

### Level 1：baseline

先做最简单、可解释、可复现的方案。baseline 可以是经典方程、朴素预测、现行规则、单源模型、小规模精确解或人工阈值。

### Level 2：针对缺陷改进

只有观察到非线性、类别不平衡、时空依赖、结构残差、资源冲突、域偏移或不确定性等具体缺陷，才增加对应模块；用同一数据和指标做消融。

### Level 3：复杂模型

深度网络、生成模型、元启发式或多模型融合需要同时满足：数据/算力足够、关键缺陷真实存在、简单方法确实不足、能设计公平验证、能解释失败边界。

推荐执行顺序：

1. 半小时内完成任务表和数据字典；
2. 为每问确定 baseline、主指标和切分方案；
3. 先跑通端到端最小方案；
4. 用残差、错误样本或约束瓶颈决定一次升级；
5. 同步保存表格、图和结论，不等最后一天补证据；
6. 最后检查摘要数字、正文表格、代码输出和结论完全一致。

## 七、十条红线

1. 不按独立对象、时间或空间划分数据，导致泄漏。
2. 用测试集选择特征、模型、阈值或超参数。
3. 只报告 Accuracy、R² 或一个综合分，不给任务匹配的指标。
4. 把相关、SHAP、注意力或熵权写成因果机制。
5. 把 t-SNE/UMAP 可视化当成分类或迁移正确的证据。
6. 因为问题 NP-hard 就直接上遗传算法，未检查精确模型和特殊结构。
7. 启发式只报最好一次，或把最好搜索结果写成全局最优。
8. 仿真和理论共享假设却称为独立验证。
9. 长期预测不给情景、区间和更新机制，报告伪精确单值。
10. 公式、图表和结论没有共同的变量名、单位和数据口径。
