## 基本信息与主线

- 题目：出血性脑卒中临床智能诊疗建模
- [正文](../../../knowledge_base/2023/E/E23100650012.md) · [PDF](../../../papers/2023/E/E23100650012.pdf)
- 题型：多表医疗数据、事件标签构造、小样本分类、非规则纵向轨迹、聚类分型、预后预测与解释。
- 主线：48 h 血肿扩张标签 → 冗余特征过滤与时间权重 → 多分类器概率预测 → 水肿总体曲线 → 患者亚组轨迹 → 治疗/滞后关系 → Stacking 预后预测 → PCA 归纳风险因素。

最值得学习的是从“所有患者一个平均曲线”出发，看到残差仍大后再引入亚组，而不是一开始就堆聚类。复杂模型由可观察缺陷触发，且上游的事件、轨迹和随访量化继续服务于预后预测。

## 三大问题链

### 血肿扩张

先按 48 小时内绝对体积增量 `≥6 ml` 或相对增量 `≥33%` 构造事件标签；再依次做低方差剔除、并查集式高相关变量过滤、发病到首次影像时间的特征权重，最后比较 KNN、SVM、RF、梯度提升并做消融。作者报告梯度提升的概率 MAE 为 0.0524。

### 水肿进展

先比较总体非线性拟合；总体残差较大后，用肘部法和多种聚类方法形成亚组，再对亚组分别拟合。作者报告谱聚类的轮廓系数 0.4186、DBI 0.8817，分组后平均残差由 1838.8871 降至 980.245。随后从类内共性、类间差异和个体案例讨论治疗，并探索血肿—水肿的时空滞后。

### 90 天预后

以 Stacking 处理多模型互补，以 Borderline-SMOTE 应对不平衡；加入随访后，将不等次数的轨迹压缩为持续时间、最大体积和扩张持续时间等五个指标。作者报告精确率/召回率由 0.835/0.821 提升至 0.923/0.894。

## 医疗纵向题的通用框架

```text
患者为独立单位
→ 以临床时间零点对齐多表与多次检查
→ 明确标签是否使用未来信息
→ 描述缺失机制和不规则随访
→ 患者级切分，再在训练折内预处理/SMOTE/选特征
→ 简单临床规则与回归 baseline
→ 轨迹、亚组或集成模型
→ 校准、外部验证、决策曲线与不确定性
```

“随访次数”本身常与病情和就诊条件有关；把最后一次或最大值作为特征时，必须确认部署时是否已经可得。治疗与结局的观察关联还受病情严重度影响，不能把模型重要性写成疗效因果。

## 方法与工具选择

- 小样本表格分类：逻辑回归、浅树/随机森林、XGBoost；优先嵌套交叉验证与校准。
- 不规则轨迹：样条/LOESS、混合效应模型、函数型数据、DTW/轨迹聚类；若样本足够再用 RNN/Transformer。
- 患者亚型：先以临床可解释特征聚类，再检查稳定性和结局差异；t-SNE 只做展示。
- 时间到事件：生存分析/竞争风险比把固定窗二分类更自然。
- 治疗效应：倾向评分、加权、匹配或因果模型；普通回归只支持条件关联。
- 工具：pandas、lifelines/scikit-survival、statsmodels、scikit-learn、tslearn、SHAP（只解释模型依赖）。

## 验证框架

1. 患者级而非影像行级划分；同一患者所有检查只能在同一折。
2. 插补、标准化、选特征和 SMOTE 全部只在训练折拟合。
3. 分类同时报告 ROC-AUC、PR-AUC、灵敏度、特异度、校准和决策曲线；概率任务不能只报准确率。
4. 轨迹拟合报告患者级残差、时间段误差和亚组稳定性；总体点级 R² 可能被重复随访主导。
5. 结论冻结后在独立医院/时间段外部验证；没有外部验证时明确是探索性模型。

## 写作与图表经验

- 摘要依次写风险、轨迹、预后三条临床任务链，每一步说明为何升级模型和关键改善。
- PDF 第 8 页先用变量类型条形图和小多面板直方图建立数据印象；小面板过多且字号偏小，自己的论文宜按临床主题分组并共享坐标/图例。
- PDF 第 27 页伪代码块展示 DBSCAN 输入、循环与输出，版式统一；但算法教材式篇幅不应挤占“为何适合本数据”的说明。
- 轨迹图应以淡色画个体、粗线画亚组均值并带置信带；分类结果用混淆矩阵、校准图和 PR 曲线；因素解释用森林图而非只给重要性柱图。
- 第一章应先画“患者—检查—时间—标签—任务”的数据关系图，这比算法总路线更能防止时间错位和泄漏。

## 可迁移经验与边界

1. 平均模型残差暴露群体异质性时，再做亚组；分组必须在新患者上有可执行的归类规则。
2. 随访量化是把不等长序列变成表格特征的实用比赛策略，但会丢失局部动态。
3. PCA、SHAP 或特征重要性只能说明统计结构/模型依赖，不能直接成为临床干预建议。
4. 比赛结果可用于方法学习，不应被当作临床诊断或疗效证据。
