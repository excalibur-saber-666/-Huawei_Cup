## 基本信息与主线

- 题目：大规模创新类竞赛评审方案
- [正文](../../../knowledge_base/2023/C/C23102540029.md) · [PDF](../../../papers/2023/C/C23102540029.pdf)
- 题型：抽象概念操作化、0-1 分配、多目标优化、评分标准化、监督学习、两阶段制度设计。
- 主线：定义交叉性/均衡性 → 0-1 专家—作品分配 → 评分习惯与作品差异指标 → 标准分修正 → 极差/创新性预测 → 两阶段分配与排名流程。

论文的核心价值在于把“公平、可比、专业、创新”拆成可计算对象，再把评价指标连接到分配优化和评分规则。此类制度题首先要说明“公平的哪一维”，而不是先选择 AHP、遗传算法或随机森林。

## 四问递进

| 问题 | 任务本质 | 方法与接口 |
|---|---|---|
| 一 | 让评审负载、作品曝光和专家间交叉更均衡 | 以 `x_ij` 表示专家 j 是否评作品 i，构造交叉量与均衡指标，用 NSGA-II 搜索多目标分配 |
| 二 | 校准专家尺度并形成可比较标准分 | 从专家评分标准差、极评、作品均值/标准差等构造专业性与合理性指标，再以线性模型修正标准分 |
| 三 | 识别极差与创新性的关系 | 线性、决策树、RF、XGBoost 比较，选 RF 拟合；再按阈值做分段关系建模 |
| 四 | 把前三问组合成完整评审制度 | 第一阶段同时用分配和指标筛选；第二阶段以极评/专业性约束再分配；最终用标准分模型排名 |

## 公平与评价题的通用框架

```text
利益相关者与决策后果
→ 公平维度（负载、曝光、可比性、专业匹配、误判代价）
→ 每个维度的可观察指标
→ 不可违反的硬约束
→ 可折中的软目标
→ 分配/评分/复议的流程模型
→ 历史回放、合成压力测试与敏感性
```

评分模型与分配模型要分开：前者定义“怎样计算成绩”，后者决定“谁评谁”。创新性、极差或专家可信度是代理量，须说明依据与失效情形；机器学习拟合历史排名只能支持与既有制度一致，不能单独证明制度更公平。

## 方法与工具选择

- 任务规模中等、约束线性：MILP/CP-SAT，可给可行性和最优性界；
- 规模很大、目标冲突：NSGA-II/局部搜索，但先做小规模精确标尺；
- 专家—作品匹配：二分图匹配、最小费用流、整数规划；
- 评分尺度校准：z-score/稳健标准化、分层模型、Many-Facet Rasch 或贝叶斯评委偏差模型；
- 创新/争议识别：先用规则和可解释回归，标签可信且样本充足时再用树集成；
- 工具：OR-Tools/Pyomo/Gurobi、NetworkX、scikit-learn、statsmodels。

验证时同时报告：逐专家工作量、逐作品评审次数、交叉分布而非均值、回避约束、方案稳定性、评分尺度变化、排名反转、不同阈值/权重下的获奖重合度，以及关键群体是否系统性受益或受损。

## 写作与图表经验

- 摘要每问都从制度目标出发，再写指标、模型与结果，避免仅列优化器。
- 符号表按索引、集合、参数、变量、评价指标分组；PDF 第 8 页层级清楚，但内容较长，局部符号可移到公式旁减轻查找负担。
- PDF 第 43 页把“调整前后极差”折线和两组 KDE 并列，适合展示制度修正的整体分布影响；横轴作品编号过密，自己的图宜取消逐个标签或改用排序后的分位数。
- 结果图应把约束满足和效果分开：一张展示负载/曝光/交叉分布，一张展示标准分和排名影响，一张展示阈值敏感性。
- 完整制度用泳道图最合适：作品、专家、系统、复议委员会各一条泳道，标出输入、分配、评分、异常识别、复议和最终排名。

## 可迁移经验与边界

1. 抽象制度目标必须操作化；指标定义比优化器更决定结论。
2. 硬约束和偏好目标不能混写；回避、每作评审数属于硬约束，交叉均衡通常是软目标。
3. 历史结果既可用作回放基线，也可能带有旧制度偏差，不能当唯一真值。
4. 公平性至少报告效率、个体/群体差异和误判后果；一个综合分数会掩盖权衡。
