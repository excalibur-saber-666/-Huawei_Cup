## 问题一：从复杂背景中提取裂隙像素

作者先用中值/频域复合去噪和 CLAHE 增强，再采用以 ResNet50 为骨干的 DeepLabV3+ 进行语义分割。裂隙像素在整幅图中占比很低，因此使用 BCE + Dice 复合损失：BCE 保持逐像素判别，Dice 直接关注前景重叠，缓解类别不均衡。迁移学习用于降低小样本训练难度。

作者报告测试集 `mIoU=0.8435、Precision=0.9356、Recall=0.8779`。PDF 的预测图与人工标签对照表明，模型能抓住主要裂隙走向，但也可见局部缺失与断裂；这恰好解释了为什么问题二还需要实例重组，而不能把分割掩码直接当作完整裂隙。

可迁移判断：

- 标注少、目标细长、背景纹理复杂：优先迁移学习的 U-Net/DeepLabV3+，损失使用 BCE/Focal + Dice；
- 没有可靠标签或算力有限：Frangi/Canny/形态学仍可做可解释 baseline；
- 传统方法已能分出大部分目标：先做受控比较，不因模型“更深”就替换；
- 后续依赖几何参数：分割评价除像素指标外，还要检查连通性、中心线偏差和实例级召回。

## 问题二：把断裂掩码重组为可计算的裂隙实例

这一问的本质不是普通聚类，而是“带已知形状先验的碎片拼接”。作者先做形态学开运算和坐标变换，再用 DBSCAN 宽松地得到若干局部碎片；选择最大碎片作为种子拟合正弦曲线，用当前模型计算其余碎片的几何一致性，吸收符合者并重新拟合，循环至不再增加碎片；最后用非线性最小二乘估计振幅 `R`、周期 `P`、相位 `β` 和中心线 `C`。

这比只调 DBSCAN 的邻域半径更有迁移价值：空间断裂不等于对象断裂，若对象具有轨迹、圆弧、正弦或骨架等形状先验，应先形成模型假设，再用模型一致性判断碎片归属。它适用于裂纹、车道线、轨迹、血管和断续轮廓重组。

作者用拟合周期收敛到钻孔周长 `94.25 mm` 作为物理一致性检查。比赛中可把验证分成三层：像素残差、实例完整率、参数物理约束；仅报告拟合图好看不够。

## 问题三：分离宏观趋势与微观粗糙度

裂隙正弦曲线同时包含宏观产状和微观起伏，直接在原始点云上计算 JRC 会把两者混在一起。作者先以拟合正弦曲线作为基准线，计算轮廓点到基准线的法向距离，将宏观趋势剥离，再比较三种离散策略：等间距采样、自适应曲率采样和关键点采样。

这一步体现了多尺度建模的通用原则：先去除不属于目标指标的低频趋势，再在残差层计算粗糙度、波动或异常。采样方法本身也属于模型；点太少会抹平峰谷，点太密可能把噪声放大。

作者用 Barton 标准轮廓作为有已知 JRC 的参照，报告关键点采样 `R²=0.9177、RMSE=1.6277`，并将其用于 10 张钻孔图像，得到 JRC 约 `1.67–8.02`。论文同时比较三种方法的误差表和采样图，比只在真实数据上给一个结果更有说服力。

## 问题四：从二维参数到三维概率网络和勘探决策

作者先把二维正弦参数转换为三维平面的倾角、倾向和法向量，再从三类证据构造相似度：空间位置、空间姿态和 JRC，权重为 `0.45/0.45/0.10`；综合连通概率超过 `0.5` 时建无向边，以裂隙为节点，通过连通分量识别三维裂隙网络。

关键不是“画出三维图”，而是承认由有限钻孔反演连续三维结构是欠定问题。论文把不确定性拆成：

1. 连接模糊度：已有裂隙对的概率接近 0.5，属于“看见了但判不清”；
2. 空间空白度：某区域远离全部钻孔，属于“根本没看见”。

两种不确定性对应两种行动：验证现有边，或探索未知区域。作者据此提出“验证—探索—再验证”的序贯补孔：P1 验证最模糊跨孔连接，P2 覆盖最大空间空白，更新概率库后再决定 P3。论文报告推荐 `P1(1500,1500)、P2(1000,1500)、P3(2500,1500)`，并强调每钻一批就重新计算，而不是一次性固定三孔。

这是一条很通用的工程决策链：预测不确定性 → 区分不确定性来源 → 把来源映射成不同实验 → 每轮观测后更新。适用于传感器布点、主动学习、故障排查、勘探和自适应试验设计。

## 什么情况下使用什么模型

| 问题结构 | 优先方法 | 使用条件与升级信号 |
|---|---|---|
| 细长目标、纹理干扰、标注充足 | U-Net/DeepLabV3+、迁移学习 | 传统阈值误检/断裂明显；同时使用 Dice/Focal 处理类别不均衡 |
| 标签稀缺、需要快速可解释结果 | Frangi/Canny/Otsu + 形态学 | 先做 baseline；若跨图像参数反复失效，再升级学习模型 |
| 对象数量未知且含噪声 | DBSCAN/HDBSCAN | 不要求球形簇；`eps` 与尺度必须做敏感性分析 |
| 断裂片段属于同一参数曲线 | RANSAC/模型驱动聚类 + 非线性最小二乘 | 有明确形状先验时，用几何一致性代替单纯空间邻近 |
| 指标只应反映局部起伏 | 去趋势/基准线—法向距离 + 多尺度分析 | 先分离宏观趋势，再计算粗糙度或异常 |
| 采样策略影响指标 | 收敛曲线、标准轮廓/合成真值 | 比较采样密度和方法，选择稳定区而非任意点数 |
| 少量截面反演三维结构 | 参数几何变换 + 概率/蒙特卡洛 | 显式传播拟合误差与模型假设，不把外推平面写成真实裂隙体 |
| 多对象关系决定整体结构 | 加权相似度图、连通分量、社区发现 | 节点/边定义必须有物理含义；阈值做灵敏度分析 |
| 需要新增观测降低不确定性 | 贝叶斯实验设计、主动学习、序贯优化 | 每轮更新模型；区分“验证模糊关系”和“探索数据空白” |

推荐工具：OpenCV/scikit-image 做滤波、阈值、形态学与中心线；PyTorch/segmentation-models-pytorch 做分割；scikit-learn 做 DBSCAN 与指标；SciPy `least_squares` 做鲁棒拟合；NumPy 做坐标变换；NetworkX 做连通分量；PyVista/Plotly 做三维可视化；若做参数不确定性传播，可用 NumPy Monte Carlo 或 PyMC。

## 四天比赛中可复用的推进方式

1. 第一天：统一像素—毫米—钻孔坐标；人工标注少量校验集；完成 Frangi/阈值/形态学 baseline，定义像素、实例和几何指标。
2. 第二天：训练或微调分割模型；把掩码转为中心线与实例；先用 RANSAC/最小二乘完成正弦参数，再处理断裂片段。
3. 第三天：去趋势并做采样收敛；用标准轮廓或合成数据验证 JRC；完成二维到三维变换、概率边和图网络。
4. 第四天上午：构造不确定性地图、阈值灵敏度与补孔序列；导出参数表、网络图和推荐坐标。
5. 第四天下午：冻结数据管线；逐问检查输入输出接口、单位、坐标系和误差传播；由最终证据表反写摘要。

## 写作手法与版式组织

- 摘要按四问依次写“困难—方法—关键结果—下一问接口”，读完即可复原整条模型链；模型名后都说明解决的具体缺陷。
- 正文页数大致为：前言与分析 5–7 页，假设符号 1 页，问题一约 21 页，问题二约 8 页，问题三约 10 页，问题四约 15 页，总结 2 页。视觉识别部分偏长，但层级清楚。
- 每问先解释上一问输出为什么仍不足，再引出本问模型，形成连续推理，而不是四个孤立算法。
- 好图承担明确证据：原图—标签—预测对比用于分割；碎片—拟合—合并图用于实例重组；标准轮廓和误差表用于采样选型；三维网络和不确定性热图用于决策。
- 结果表保持“对象 ID + 参数 + 单位 + 误差/置信信息”；三维图必须配坐标轴、钻孔位置和图例，避免只展示炫目的曲面。
- 模型总结按问题逐项回扣优点、局限和改进，适合作为终稿一致性检查表。

## 我会怎样改造成更稳的比赛模板

1. 第一页总路线图明确每问的输入、输出、单位和误差如何进入下一问。
2. 分割模型同时报告像素指标和实例级连通/中心线误差，防止像素分数高但几何不可用。
3. 用“传统 baseline → 深度分割 → 几何后处理”的递进消融，证明复杂模块的增量。
4. 将 DBSCAN、连通阈值和相似度权重做统一敏感性分析；经验权重写成校准参数，不写成普适常数。
5. 对二维到三维的参数做 Monte Carlo 传播，输出边概率区间；三维平面只表述为潜在延伸趋势。
6. 把一次性补孔改成真正滚动的伪代码：观测、更新、重算不确定性、选择下一孔、停止。
