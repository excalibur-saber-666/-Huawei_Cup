- 题型：旋转机械信号处理、物理特征构造、源域监督分类、无监督域适应、伪标签与可解释诊断。
- 核心主线：工况匹配与重采样 → 文件级信号切窗 → 时域/频域/包络/时频特征 → 源域分类 baseline → 源/目标分布诊断 → DANN + MMD + 伪标签 → 目标文件预测 → 事前/迁移过程/事后解释。

这篇论文最值得学习的是把“机理特征”和“深度表征”并列：故障特征频率、包络能量等负责物理可解释性，小波图与 ViT/ResNet-CBAM 补充复杂模式；域适应再围绕“消除工况差异但保留类别差异”组织。

## 问题一：从振动信号得到可迁移表征

作者选择与目标域转速接近的源域数据，将采样率统一到 `32 kHz`，用长度 `1024`、步长 `512` 的滑窗生成样本，并按信噪比、均方根和波峰因子筛选数据。特征分为两类：

1. 手工特征：均值、RMS、峭度、波形/脉冲/峰值因子，频谱质心、频谱熵、特征频带能量，包络 RMS/峰值，小波能量等；
2. 深度特征：把振动信号变成小波时频图，由 ViT 提取 128 维表征。

机理主线是局部缺陷产生周期冲击；依据滚动体数量、节径、滚动体直径、转速和接触角计算 `BPFO/BPFI/BSF`，再在频谱/包络谱及其边频带中寻找对应峰值。正常、外圈、内圈、滚动体故障的差别不只体现在总体能量，也体现在冲击周期、调制和时频能量聚集。

可迁移经验：先把采样率、转速和频率轴统一，再比较特征频率；转速变化明显时应改用阶次跟踪/角域重采样，不能直接比较固定 Hz 峰值。窗口长度由最低关注频率和所需周期数决定，步长只控制样本数量，不会增加独立信息。

## 问题二：源域分类只是迁移的起点

作者融合手工和 ViT 特征，比较 KNN、TCN、DenseNet、ResNet-CBAM，并在三种训练/测试比例下报告 Accuracy、Precision、Recall、F1、混淆矩阵和 t-SNE。作者报告 ResNet-CBAM 在 7:3 划分下准确率 `0.998`。

模型选择应根据输入形态：

- 表格手工特征：逻辑回归、SVM、RF/GBDT 是强 baseline；
- 原始一维序列：1D-CNN/TCN 适合局部冲击和长依赖；
- 时频图：2D-CNN 通常先于 ViT；样本和预训练不足时 ViT 未必占优；
- 多传感器/多窗口：后期融合或注意力模型，但必须按文件/试验组验证。

最重要的验证单位不是滑窗，而是原始文件或独立试验。重叠窗高度相似，若随机拆到训练和测试两边，指标会乐观；比赛应使用 GroupKFold/Leave-One-File-Out，并把标准化、特征选择和数据增强全部放入折内。

## 问题三：无标签目标域的迁移诊断

作者用源域均值和标准差对目标特征标准化，再用 MIC 选择跨域共性特征；以 ResNet-CBAM 为特征提取器/分类器，联合 DANN 和 MMD：

- 源域分类损失保留故障判别性；
- 域判别对抗使特征难以区分源/目标；
- MMD 直接缩小两域分布距离；
- 目标域聚类与余弦距离生成伪标签，再输出 16 个文件类别。

作者用迁移前后 t-SNE、MMD、目标特征内聚性和跨域匹配度做无标签证据，并给出 DANN、MMD、联合方法的消融；报告 MMD 从 `0.89` 降到 `0.15`、内聚性 `0.91`、匹配度 `0.89`。

这里要区分三种结论：

1. 域不可分/分布距离降低：说明对齐更强；
2. 类内更紧、与源类中心更近：说明伪标签结构更自洽；
3. 目标域真实准确率：只有已知目标标签或受控替代验证才能得到。

因此，无标签 A–P 的预测可以作为提交结果，但不能用预测自身证明正确。模型选择更稳的方式是：源域留文件/留工况验证、构造已知标签的“伪目标域”做迁移实验、比较 source-only/对齐/伪标签消融、检查伪标签稳定性和拒识率。

## 问题四：把解释分成三个时刻

作者把解释性分为：

1. 事前：模块化架构、物理特征和损失项各自承担什么任务；
2. 迁移过程：MMD、域判别准确率、内聚性、跨域匹配和特征图如何随训练变化；
3. 事后：用 SHAP 分析频点/特征对单样本和全局预测的贡献，并与包络谱故障频率对应。

这种结构比“最后补一张 SHAP 图”更完整。真正可信的解释还要验证：删除高贡献频带是否显著降低预测、解释在相邻窗口/噪声扰动下是否稳定、贡献峰是否落在理论故障频率及边带附近。SHAP 表示模型依赖，不自动等于物理因果。

## 什么情况下使用什么模型

| 问题结构 | 优先方法 | 使用条件与升级信号 |
|---|---|---|
| 稳态、转速固定、机理清楚 | 包络谱 + BPFO/BPFI/BSF + 阈值/浅层分类 | 首选可解释 baseline，样本少时尤其有效 |
| 转速随时间变化 | 阶次跟踪、同步重采样、时频脊线 | 固定频率峰漂移时升级，不直接在 Hz 轴对齐 |
| 非平稳冲击与调制 | STFT/CWT/DWT、谱峭度 | 需要定位“何时—何频率”发生能量聚集 |
| 中小样本表格特征 | SVM、RF、GBDT | 训练快、可解释、适合比赛 baseline |
| 原始一维序列且数据较多 | 1D-CNN、TCN | 自动学习局部冲击；先与手工特征 baseline 比较 |
| 时频图样本充分/有预训练 | 2D-CNN、ViT | 2D-CNN 是简单强基线；ViT 需足够数据或迁移预训练 |
| 仅协变量偏移、类别语义一致 | CORAL/MMD/DANN | 先确认类别集合一致；分布对齐不等于类别对齐 |
| 类条件分布错位 | CDAN、类条件 MMD、原型对齐 | 全局对齐造成类混叠时使用 |
| 伪标签较可靠 | 高置信自训练、原型更新 | 使用阈值、温度校准和一致性；低置信样本拒识 |
| 目标域可能含未知故障 | 开集域适应、异常检测 | 不能强迫每个样本进入已知四类 |
| 需要解释单次报警 | SHAP/Integrated Gradients + 故障频率核对 | 同时做删除/扰动忠实度与稳定性检验 |

推荐工具：SciPy.signal 做滤波、Welch、Hilbert 包络和重采样；PyWavelets/librosa 做小波/时频图；scikit-learn 做 GroupKFold、SVM/RF/GBDT、校准与聚类；PyTorch 做 1D-CNN/TCN/ResNet、DANN/MMD；Captum/SHAP 做解释；UMAP/t-SNE 仅作可视化，不能替代定量验证。

## 四天比赛中可复用的推进方式

1. 第一天：建立文件/工况/采样率/转速数据字典；按原始文件分组；完成重采样、去趋势、Welch/包络谱、故障频率与浅层 baseline。
2. 第二天：构造时域/频域/包络/时频特征；比较 SVM/RF/GBDT 与 1D-CNN/TCN；用留文件验证选源域模型。
3. 第三天：量化域偏移；建立 source-only、CORAL/MMD/DANN 和类条件/伪标签版本；在受控伪目标域上消融选型。
4. 第四天上午：生成目标预测、置信度、拒识/稳定性分析；做机理一致性和解释忠实度检查。
5. 第四天下午：冻结数据管线；检查窗口泄漏、源统计量、标签映射和图表单位；由证据表反写摘要。

## 写作手法与版式组织

- 摘要两页按“特征—源域—迁移—解释”四问写，模型名后都有输入、作用和作者报告指标；目标文件标签单独列出，便于复核。
- 正文约 37 页：问题一 9 页、问题二 6 页、问题三 8 页、问题四 6 页，附录从 38 页开始。篇幅把最多空间留给特征机理和迁移证据，结构合理。
- 第 5 页先给 BPFO/BPFI/BSF 公式，后续图表不断回扣特征峰；这比先堆模型再解释信号更自然。
- 表 7 在同一表中比较四模型、三种划分和四指标；图 8 用同版式展示 t-SNE，读者能快速比较，但应配文件级验证避免把可视化当精度证据。
- 迁移部分按“域偏移现象 → DANN/MMD 损失 → 训练流程 → 目标预测 → 消融”展开，模型升级理由明确。
- 可解释性章节先给模块表，再给迁移指标、SHAP 总体图和单样本图，形成结构—过程—决策三层证据。
- 图表应统一状态颜色和频率单位；包络谱图标出理论频率及倍频/边带，t-SNE 图注明仅供探索。

## 我会怎样改造成更稳的比赛模板

1. 所有切窗先分文件再分折，禁止同一原始文件的重叠窗跨训练/验证。
2. 建立 `手工特征+SVM/RF`、`1D-CNN`、`时频图CNN` 三条并行 baseline，再决定是否加入 ViT。
3. 把特征频率换算成阶次或随转速自适应频带，避免源/目标转速不同造成伪域差异。
4. 域适应比较 source-only、CORAL/MMD、DANN、类条件对齐和伪标签；在有标签的受控伪目标域选择方案。
5. 目标输出除类别外加入置信度、最近原型距离和未知类拒识；不强迫异常样本进入已知类别。
6. 解释部分加入频带删除、噪声扰动和窗口重采样实验，证明解释忠实且稳定。
