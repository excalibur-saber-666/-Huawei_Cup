这篇论文最值得学习的是没有直接把“趣味性、幻境感、美学相似度”送入 AHP 或 TOPSIS，而是先找到它们对应的体验过程和空间对象，再逐层建立可观察量、指标和综合映射。

## 问题一：把“移步异景”建成路径上的动态体验

作者先把道路、半开放建筑与障碍物坐标统一到米制平面，构造可通行域，再通过骨架/中线提取把二维廊带压缩成图 `G=(V,E)`。节点表示出入口、转折或交叉位置，边保留长度、空间类型及沿途景观信息。

趣味性不是一个静态园林属性，而是观察者沿路线移动时形成的序列体验。作者把它拆为：

1. 景观组合随位置的变化，即异景程度；
2. 转折和交叉是否适量，而非单调追求越多越好；
3. 室外与半开放空间的节奏是否接近目标比例；
4. 路径长度是否处于可接受区间；
5. 重复路段是否造成体验冗余。

在此基础上建立加权趣味性函数，并把景观收益、长度与重复惩罚写入路径代价，用改进遗传算法搜索入口到出口的游线。论文没有只展示“最优路线”，还把拙政园模型路线与官方推荐路线进行对照：官方路线在转折和异景程度上更强，模型路线交叉更少、效率更高，说明“趣味性”包含不同偏好维度，不应压缩成唯一绝对答案。

可迁移经验：先定义路径状态和体验序列，再定义局部边收益与整条路径目标。若目标冲突明显，优先输出 Pareto 候选或偏好情景，不要在没有依据时强行固定一个权重。

## 问题二：把“小中见大”拆成分布与开合节奏

作者先把园林划分为约 `5 m × 5 m` 的局部观景单元，提取建筑、半开放建筑、道路、山石、水体、植物六类要素的数量、面积、形状、比例、离散度与位置等特征。

为了避免普通聚类得到空间碎片，使用 GMM 负责特征相似性，MRF/Potts 先验负责相邻单元的空间连续性，并用距离衰减和道路/水体阻隔修正邻接权重。由此得到连通、可解释的水景、山石、植被、建筑/半开和过渡主题区。

“幻境感”继续拆成两个维度：

- 元素分布：主题丰富但不过度碎裂，框景与临水开敞能够协同；
- 开合节奏：沿主游线计算各区开阔度减围合度，相邻差分形成“合→开、开→合、平缓过渡”的节奏序列。

论文以寄畅园为 100 分标尺，把元素分与开合节奏分对标后线性融合，并对空间先验、距离尺度、碎边惩罚、融合权重、网格步长等做单参和联合扰动，使用 Kendall τ、Top-3 保持率、名次变化、分数区间和强转场比例评价稳定性。

可迁移经验：空间评价不能只用全局平均值。先建立局部分析单元，再处理空间相邻与阻隔；“丰富”与“凌乱”、“开阔”与“围合”通常不是单调好坏，而是需要适宜度或节奏指标。

## 问题三：把前两问的中间量变成可比较表征

作者将路径长度、转折/交叉、异景程度、山水建筑植物道路比例、开阔/围合等组成综合向量：

- 连续特征用余弦相似度比较整体方向；
- 主导元素集合用 Jaccard 相似度比较组合；
- 融合系数不直接拍定，而是在网格上扫描，以轮廓系数、cophenetic 相关和 bootstrap ARI 的组合分数选择，并在邻域内做敏感性检查。

随后用相似度热力图和层次聚类提炼共有规律，并把整套流程应用于题目样本外的鹤园：重新提取要素、求路径与幻境分、计算与十园的相似度并观察聚类位置。这个过程验证的是“流程能在新对象上运行且结果与已有认知相容”，若要证明真实美学判断准确，还需要独立专家评分、游客实验或其他外部准则。

论文最后增加“自然—人工融合度”和“水陆交融度”，展示如何从前述不足出发补充新维度，而不是无边界地堆指标。

## 抽象概念题的通用建模框架

```text
抽象概念
→ 明确观察主体、时间/空间尺度与比较对象
→ 文献/专家给出概念维度
→ 为每个维度寻找可观察代理量
→ 方向、边界、适宜区间与非补偿规则
→ 最简单等权/规则 baseline
→ 权重或映射学习
→ 排名、分级、优化或相似度
→ 构念效度、外部准则、稳健性与泛化验证
```

每个箭头都要回答“为什么”。特别要区分：指标可计算，不等于概念已被正确测量；结果与常识相符，不等于模型已经通过独立验证。

## 什么情况下使用什么模型

| 问题结构 | 优先方法 | 使用条件与升级信号 |
|---|---|---|
| 抽象概念刚开始量化 | 概念树 + 等权标准化加总 | 先验证指标代表性；不急于上 AHP/TOPSIS |
| 专家偏好明确且层次稳定 | AHP/德尔菲 + 一致性检验 | 专家来源可追溯，做多专家与权重扰动 |
| 希望利用样本差异定权 | 熵权/CRITIC | 差异大只表示信息量大，不自动等于价值重要 |
| 指标存在不可补偿底线 | 门槛、乘法效用、Choquet/规则系统 | 不能让一个极差维度被其他高分完全抵消 |
| 平面通行与游线体验 | Shapely/骨架化 + NetworkX + 多目标路径 | 先保证几何合法、图连通与路线可回代 |
| 局部单元既看特征又看邻接 | GMM/K-means + MRF/谱聚类 | 普通聚类产生碎片或忽略阻隔时升级 |
| 比较不同对象整体形态 | 标准化向量 + 余弦/欧氏/Gower | 距离必须匹配连续、类别、集合数据类型 |
| 比较元素集合或组合 | Jaccard/加权 Jaccard | 不把连续比例粗暴二值化，阈值需做敏感性 |
| 目标冲突的路线/设计 | ε-constraint、Pareto、NSGA-II | 输出折中集合与偏好解释，不只给单一点 |
| 有专家或游客评价标签 | 回归/有序模型/学习排序/贝叶斯标定 | 用对象级交叉验证、校准和不确定性区间 |
| 多模态数据量小 | 手工几何/图/视觉特征后期融合 | 先于深度多模态；复杂模型要有预训练或独立验证 |

推荐工具：Shapely/GeoPandas 做缓冲区、相交和多边形；scikit-image 做骨架/栅格；NetworkX/OSMnx 做图与路径；scikit-learn 做聚类、相似度和 bootstrap；SciPy 做统计与距离；pymoo/DEAP/OR-Tools 做多目标或组合优化；QGIS 做空间检查；Matplotlib/Seaborn 做路径、热力图、平行坐标和敏感性图。

## 验证这类模型的四层证据

1. 构造正确：几何合法、路网连通、指标方向和量纲正确、路线逐边可行。
2. 构念效度：指标与理论概念、专家判断或问卷量表之间有明确对应；比较收敛效度与区分效度。
3. 稳健性：权重、阈值、网格尺度、缺失/噪声和随机种子扰动下，分数与排序是否稳定。
4. 外部效度：新园林、新人群或新地区上，与独立专家评分、游客行为/满意度或既有路线对照。

“把同一套指标应用到新对象”是可迁移性检查，但若没有外部真值，只能证明流程可运行和结果自洽，不能直接证明审美判断准确。

## 四天比赛中可复用的推进方式

1. 第一天：阅读题意和领域文献，画概念树；统一坐标与单位，完成几何质检；建立等权/最短路等 baseline。
2. 第二天：完成路径图、局部空间单元、核心指标和可视化；每个指标写出方向、尺度与概念依据。
3. 第三天：加入空间约束、权重/相似度或多目标优化；做官方方案、专家准则或简单模型对照。
4. 第四天上午：权重/阈值/网格/噪声扰动，完成新对象外部案例与不确定性表达。
5. 第四天下午：冻结口径，逐项回代路线和公式；用“概念—代理量—证据”表反写摘要和结论。

## 写作手法与版式组织

- 摘要按“趣味性—幻境感—相似度”三问展开，每问都写概念如何操作化、使用的模型、验证方式和关键输出；算法名服务于任务链，不单独堆砌。
- 正文 60 页：问题一约 23 页、问题二约 19 页、问题三约 10 页，剩余篇幅用于共用定义与评价。篇幅与数据处理和模型复杂度基本匹配。
- 每问开头先给一段自然语言拆解和流程图，再进入局部公式；读者先知道“为什么”，再看“怎么算”。
- 地图展示空间结果，热力图展示局部强度，相似度矩阵展示成对关系，雷达图只用于少量同尺度指标；表格保留精确分数与排名。
- 第 30 页用官方路线与模型路线并排、再用同口径雷达图比较，形成“方案—指标—解释”闭环；这种对照比单独展示模型路线更有说服力。
- 第 49—50 页把灵敏度参数、判定指标和图放在一起，写作上应进一步明确“预设合格阈值”和“实际是否达到”是两件事。
- 图表配色应固定空间类别，平面底图降饱和，优化路线用单一高对比色；坐标、比例尺、入口出口、方向和单位必须完整。

## 我会怎样改造成更稳的比赛模板

1. 先用等权评价和最短/少重复路线建立 baseline，再由“忽略视域、空间连续性或偏好差异”的证据触发复杂模型。
2. 建立指标审计表：概念维度、代理量、方向、量纲、数据源、理论依据、可操纵性、冗余和失效情形。
3. 将专家/游客评分留作外部准则，不参与全部指标和权重的反复调节；避免用同一认知同时建模和验证。
4. 对排序同时报告名次、分数区间与成对反转概率；不把微小分差解释为真实审美等级差异。
5. 路线优化输出 3—5 条 Pareto 候选，分别代表省时、少重复和高异景偏好，并与官方路线公平比较。
6. 新园林验证预先冻结指标、权重和阈值；若必须再校准，明确区分“迁移测试”和“重新建模”。
