## 基本信息与主线

- 题目：机器学习驱动的面向 MIMO-OFDM 的链路速率预测

- 题型：高维复数信道数据解析、物理层降维、离散有序目标预测、物理—数据融合、分组泛化、TxBF 场景迁移。
- 核心主线是“物理模型先解释主趋势，机器学习只补剩余结构”：CSI → 每个子载波 SINR → EESM 等效 SINR → Isotonic 单调映射作为 baseline → 统计/SVD 特征与树模型补残差 → OOF 校准与融合。

## 建模过程：从原始信道到可用预测

### 第一步：先明确样本单位、场景和目标形式

每个样本包含 `2×4×122` 的复数 CSI、底噪、TxBF 开关和速率/MCS 标签。作者先按 TxBF 开关分场景，再将 CSI 解析为 122 个子载波上的信道矩阵。这个步骤体现了数据题的第一原则：先确定一行数据代表什么、哪些行属于同一设备/文件/时段、预测时哪些特征真正可获得。

目标虽然用数值表示，但本质上具有离散、有序的速率档位特征。因此论文同时报告连续误差和离散命中，而不是只把它当普通连续回归。

### 第二步：问题一先建立物理可解释 baseline

作者由信道矩阵与底噪计算每个子载波的 SINR，再用 EESM 把 122 维序列压缩为一个等效 SINR。EESM 的参数 `α、β` 通过粗网格搜索和局部精炼确定，等效 SINR 到速率的映射则使用 Isotonic Regression，保证信道质量提高时预测速率不下降。

这个 baseline 很适合竞赛：变量少、计算快、符合通信机理、便于画出“等效 SINR—速率”关系。它也给后续复杂模型提供明确参照：如果残差仍随频域起伏、底噪或设备来源呈结构变化，才说明需要升级。

### 第三步：只让机器学习学习物理模型遗漏的信息

论文在 EESM + Isotonic 上增加 HGBR。输入不是盲目塞入全部原始矩阵，而是构造：线性域/dB 域统计量、分位数、偏度/峰度、阈值占比、分段 EESM、底噪和来源特征，并对主要等效 SINR 特征施加正单调约束。

堆叠时使用折外预测（OOF），避免把同一样本的训练拟合值当成二层模型输入；最终用学习得到的权重融合物理基线与 HGBR。作者报告问题一 `R²=0.828、RMSE=40.657、MAE=30.952`。

可迁移思想是：

1. 先建立可解释的主效应；
2. 检查残差还与什么有关；
3. 用低维、带物理意义的特征补充；
4. 保留单调性等硬知识；
5. 如果融合权重退化到 0 或 1，就接受简单模型，不强行证明融合有效。

### 第四步：问题二用纯数据模型做平行对照

问题二构造 259 维特征，包括各子载波线性域和 dB 域表示及统计量，使用随机森林拟合非线性关系。随机搜索选择树数、深度、叶节点样本量和特征抽样比例；对标签长尾使用逆频权重；随机森林输出再经 Isotonic 校准并贴近训练标签集合。

这一问的价值不是“随机森林一定最好”，而是建立一条与物理模型平行的数据驱动路线。作者报告 `R²=0.765、RMSE=47.557、MAE=36.846`。在比赛中，可以据此比较：物理压缩是否丢失重要信息，还是高维模型只是增加复杂度。

### 第五步：问题三根据 TxBF 机制重新设计特征

开启 TxBF 后，信道结构发生变化。作者不是直接沿用问题二，而是对每个子载波做 SVD，提取最大/次大奇异值、条件数和成形增益；再组合 15 维统计特征、4 维 SVD 特征、10 维多 `β` EESM 特征和 1 维底噪，共 30 维输入 HGBR。

同时保留 EESM + Isotonic 物理基线，使用带岭闭式权重进行凸融合，再基于 OOF 预测做二次 Isotonic 校准。作者报告物理基线 `R²=0.628`，ML 与融合模型均为 `R²=0.702、RMSE=55.689`；融合权重最终使方案退化为 ML 模型，说明物理信息已通过 EESM 特征进入学习器。这个结果很好地示范了“模型融合也允许没有额外收益”。

## 什么情况下用什么模型

| 观察到的问题结构 | 优先模型 | 选择理由 |
|---|---|---|
| 数百个子载波需要压成一个链路质量指标 | EESM/MIESM | 物理含义明确、参数少，适合作为 baseline |
| 输入与有序目标应保持单调 | Isotonic Regression、单调约束 GBDT | 不预设线性形状，同时保证物理合理性 |
| baseline 残差仍有非线性结构 | HGBR、LightGBM/XGBoost | 适合中等样本和表格特征；可直接学习残差或融合 |
| 原始高维特征关系复杂、希望快速建立强基线 | 随机森林 | 预处理需求低，能处理非线性和交互，可做特征筛选参考 |
| 多天线矩阵结构决定性能 | SVD 特征、奇异值/条件数 | 用少量结构量概括空间增益，比直接展开矩阵更易解释 |
| 标签离散且有顺序 | 回归 + 最近档映射，或有序分类 | 同时报告连续误差和 Top-1/±1 档命中 |
| 同设备、同文件或相邻时刻高度相关 | GroupKFold/按时间留出 | 避免随机行切分带来的同域泄漏 |
| 训练和部署场景不同 | 分组验证、域适配、校准 | 先判断分布偏移，再决定 CORAL、重要性加权或重标定 |
| 决策需要保守速率 | 分位数回归、保形预测 | 输出不确定区间，再按风险选择下分位速率 |

建议工具：pandas/openpyxl 读取表格；NumPy 解析复数矩阵和 SVD；SciPy 做参数搜索；scikit-learn 的 GroupKFold、IsotonicRegression、RandomForestRegressor、HistGradientBoostingRegressor；Matplotlib/Seaborn 绘制分布、残差、混淆矩阵和校准图。

## 验证协议是这类题的核心模型之一

1. 先定义独立单位：同一 MAC、文件、终端或连续采集片段不能被拆到训练与验证两边。
2. 所有可学习步骤都必须在折内完成：参数搜索、标准化、样本权重、Isotonic 校准和二层融合。
3. 堆叠模型的二层输入用 OOF 预测生成；最终预测无标签数据 B 时，再用全量 A 重训。
4. 连续指标报告 `RMSE/MAE/R²`，有序离散决策报告 `Top-1、±1档` 和混淆矩阵。
5. 每个设备/文件单独列指标，同时报告跨组均值和波动；只有少量独立组时，逐组结果比一个总均值更重要。
6. 无标签数据 B 只能输出预测分布、覆盖范围和异常检查，不能把其预测结果称为已验证精度。

## 四天比赛中可复用的推进方式

1. 第一天：解析 CSI、底噪和标签；确认独立分组；完成 EDA 与 EESM/简单统计 baseline。
2. 第二天：拟合 EESM 参数与单调映射；建立 GroupKFold 评估脚本；画残差并找出 baseline 的结构性不足。
3. 第三天：加入 HGBR/RF 和 SVD/统计特征；使用 OOF 做校准或融合；完成消融与分组结果。
4. 第四天上午：处理 TxBF/域偏移、不确定性和最终预测；冻结数据管线并统一导出表图。
5. 第四天下午：摘要从最终指标表生成；检查训练/验证口径、单位、图题、指标名称和结论边界。

## 写作手法与篇幅组织

- 摘要按三问分别写“场景—物理处理—学习模型—验证指标”，信息密度高；关键词紧扣 EESM、RF、HGBR、Isotonic。
- 正文先集中约 13 页做数据观察，再用约 11 页写问题一、9 页写问题二、11 页写问题三，最后 2 页评价与改进。结构完整，但比赛终稿可压缩重复 EDA，把更多篇幅留给验证口径和消融。
- 每问保持“问题分析 → 数据预处理 → 模型 → 求解 → 结果”的固定节奏，读者容易比较三种场景。
- 图 5-1 的四区流程图把准备、baseline、增强、验证闭环放在一页，是很好的总览模板。
- 结果部分不只给一个总指标，还配参数表、残差图、混淆矩阵、特征重要性和分设备预测，形成多角度说明。
- 问题三主动说明融合权重为 0、融合没有超过 ML，这是值得学习的写法：如实呈现模型选择结果，而不是强行保留复杂模型。
- 图表应一图一证据：参数扫描说明稳定区间，残差图说明系统偏差，混淆矩阵说明相邻档误差；装饰性较强但信息增量小的图可以删减。

## 我会怎样改造成更稳的比赛模板

1. 在问题分析后增加“样本独立单位与部署场景”小节，先确定切分协议。
2. 用统一表格列出每一层的输入、输出、是否在折内拟合、部署时是否可得。
3. 采用 baseline → 残差诊断 → 增强模型 → 消融，而不是一开始并列很多算法。
4. 把 `EESM`、`EESM+校准`、`+统计特征`、`+SVD`、`+HGBR` 做成递进消融表。
5. 特征重要性只用于解释模型依赖，不写成物理因果；配合置换重要性或分组删减实验。
6. 给最终方案增加预测区间或保守速率规则，使指标与真实链路选择决策连接起来。
